# 数字人平台矩阵 · C 路结论

> 文档类型：结论文档（整合）｜ 日期：2026-10-06 ｜ 对应底稿：`09_调研底稿与素材/20261006_四路调研/C路_数字人平台调研底稿.md`
> 主线：数字人是 WNF-001（Seedance 2.0 不支持真人人脸正脸视频）的**合规替代方向**——目标是"正脸写实 + 口播讲解项链佩戴效果"。
> 证据等级：✅已查证 / 🔶经搜索补充 / 🟡一方说法 / ⚪未核实（详见底稿逐条回源）。

## 一、一句话结论

对本项目（线下珠宝客户、中文、微信/抖音直发、低成本量产）而言，**数字人能部分替代正脸口播，但不能完全替代"实物+锁骨侧脸佩戴"**：
- 要"正脸口播讲解"——**国内 SaaS 首选剪映数字人（链路最短）或蝉镜/闪剪（电商向、便宜）**，用**员工本人形象**克隆，规避肖像权；
- 要"超高写实正脸"——国内 SaaS 仍达不到真人实拍质感，HeyGen/D-ID 效果好但**海外、数据出境、不适合国内投流**；
- 合规底线是硬墙：**AI 数字人视频必须显著标识 + 导出元数据隐式标识 + 用真人形象必须书面授权**，否则平台限流/封禁 + 民事侵权。

**合规落地 3 条硬动作（本项目必做）**：
1. 所有 AI 数字人口播视频导出后，**画面起始/角落加"AI生成"显著标识**，并保留平台元数据隐式标识，不裁剪水印；
2. 数字人形象**只用员工本人**（自己录素材克隆），如用模特/客户形象必须签**书面肖像权+声音授权书**（商用范围+期限）；绝不克隆明星/网红；
3. 商品**头图/主图必须实物图**（抖音规则3.4），数字人口播只用于讲解段，不替代产品微距实拍。

## 四、珠宝口播选型建议（与"锁骨+侧脸"现有方案对比）

### 4.1 数字人能否承担"正脸写实+口播讲解项链佩戴"？
- **能承担"口播讲解"这一半**：国内 SaaS（剪映/蝉镜/闪剪）可生成正脸口播数字人，输入文案即出讲解视频，成本低（每分钟几元起），适合批量做"项链卖点讲解"口播。
- **承担不了"正脸超写实佩戴+火彩展示"那一半**：① 数字人正脸写实质感仍逊真人，珠宝微距火彩/金属反光是数字人短板；② 数字人"手持/佩戴项链"的自然持物动作弱（D-ID/照片型尤甚）；③ 国内投流还被要求"商品主图必须实物图"。

### 4.2 与现有"锁骨+侧脸佩戴"方案的取舍

| 维度 | 现有方案：实物微距 + 锁骨侧脸佩戴(Seedance) | 数字人正脸口播(本路) |
|---|---|---|
| 产品保真 | ⭐最强（实物图生视频，火彩/镶爪/倒影真实） | 弱（数字人戴的是"画上去的项链"，产品保真差） |
| 人脸正脸 | ❌受 WNF-001 限制（只能侧脸/锁骨） | ✅可正脸口播 |
| 口播讲解 | ❌Seedance 不支持真人口型 | ✅天然强项（文案驱动口型） |
| 成本 | 低（抽卡量产） | 低-中（SaaS 每分钟几元） |
| 合规 | 侧脸产品特写，标识要求相对低 | **必须AI显著标识+授权书**，合规成本高 |
| 适用 | 产品展示/氛围大片 | 卖点讲解/知识口播/直播引流 |

### 4.3 推荐组合（结论）
1. **主力不变**：产品微距 5 要素实拍 + 锁骨侧脸佩戴图生视频（保真最强，已过 G1–G5）——继续作为给客户看的"效果展示"成片。
2. **新增数字人补位**：用**剪映数字人（员工本人形象）**批量做"项链卖点讲解口播"短视频（如"蓝宝石 4C、怎么选扣环"），作为引流/讲解内容，**与佩戴展示片分开成片**，避免数字人"假佩戴"损害产品信任。
3. **不要做的事**：不要用数字人做"正脸佩戴特写"冒充真实试戴；不要用 HeyGen/D-ID 做国内投流（数据出境+支付）；不要碰 Wav2Lite 商用；不要克隆非授权真人形象。
4. **升级触发**：若客户明确要"高质感正脸口播大片"，按治理卡需暂停重评——此时才考虑硅基/腾讯云超写实定制或真人实拍+AI 后期（WNF-001 既定替代方向）。
