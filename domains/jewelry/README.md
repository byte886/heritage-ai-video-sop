## 实例运行规则

- **通用优先**：先在仓根 `01_结论与产出/` 找通用 SOP（导演思维/分镜、质量门禁 v2.0、工具选型、来源索引），本目录只放珠宝专属差异。
- **质量门禁**：所有珠宝成片走 `01_结论与产出/全链路质量门禁_v2.0.md`（五阶段迭代复查）。
- **行业注记**：SOP 内"适用：线下珠宝商（鉴藏体系）"等限定语保留在本目录文件，通用层不出现行业限定。
- **决策/调研归位**：珠宝专属决策（ADR-001/002、珠宝设计评估）在 `02_决策记录/`；调研底稿在 `09_调研底稿与素材/`（含收藏视频分析/四路调研等，不强制移动历史，本索引即归位说明）。
