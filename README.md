## 快速开始
1. 先读 `00_项目总纲.md`（通用生产纲领与当前状态）
2. 通用能力 → `01_结论与产出/`：导演思维与分镜生成SOP / 音频选择与生成SOP / 工具选型参考 / 来源索引 / 全链路质量门禁 v2.0
3. 行业实例 → `domains/<行业>/`（当前：`domains/jewelry/`，含国内AI生成珠宝实操SOP、无模特版出片SOP、小红书运营/合规/私域系列、方案效果图等；实例 README 即该行业导航）
4. 进度/问题 → `03_进行中的任务/TASK_STATUS.md` + `ISSUES.md`
5. 调研证据 → `09_调研底稿与素材/`（只读存档，按行业实例索引归位）
6. 评估/迭代规则 → `02_决策记录/评估迭代机制.md`（五道门禁）+ `01_结论与产出/全链路质量门禁_v2.0.md`（可勾选检查项）
