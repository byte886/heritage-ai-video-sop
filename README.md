## 快速开始
1. 先读 `00_项目总纲.md`（项目定位与当前状态）
2. 要按 SOP 出图/出视频 → 读 `01_结论与产出/国内AI生成珠宝实操SOP.md`（总 SOP）；执行无模特版出片 → 直接读 `01_结论与产出/无模特版出片SOP.md`（分步执行版）；查工具选型细节 → `01_结论与产出/工具选型参考.md`；查外部来源链接 → `01_结论与产出/来源索引.md`；配配音/BGM/拟音 → `01_结论与产出/音频选择与生成SOP.md`
3. 要查收藏素材体系（八支柱能力地图/提示词/案例索引） → 读 `01_结论与产出/收藏素材体系总纲_rev20261006.md`（09 原版只读存档）
4. 要查进度/问题 → `03_进行中的任务/TASK_STATUS.md` + `03_进行中的任务/ISSUES.md`
5. 要查调研证据 → `09_调研底稿与素材/`（16 份底稿，按体系总纲索引）
6. 要了解评估/迭代规则 → `02_决策记录/评估迭代机制.md`（五道门禁，视频最后检查）+ `03_进行中的任务/质量评估与迭代机制/全链路质量门禁_v2.0.md`（可勾选检查项）
