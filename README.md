## 快速开始
1. 先读 `00_项目总纲.md`（项目定位与当前状态）
2. 要按 SOP 出图/出视频 → 读 `01_结论与产出/国内AI生成珠宝实操SOP.md`（总 SOP）；执行无模特版出片 → 直接读 `01_结论与产出/无模特版出片SOP.md`（分步执行版）
3. 要查进度/问题 → `03_进行中的任务/TASK_STATUS.md` + `ISSUES.md`
4. 要查调研证据 → `09_调研底稿与素材/`
