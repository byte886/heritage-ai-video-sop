### 簇 1｜活人感 / 人物真实感（#8 活人感 + #6 姜颜微表情）——物理词翻译清单

**跨视频关键经验汇总：**
- "活人感"的本质＝**不完美的生命细节**，而非"精致完美"（#8 梳子玩Ai）。
- 姜颜篇印证同一原则：嵇康戴枷特写"胡须与碎发自然、无过度磨皮"，女主"眼神冷峻克制"——悲情高级感靠的也是**保留瑕疵、不过度美颜**（#6）。
- 物理词翻译清单（把"像真人"这种抽象词翻译成可写进提示词的物理描述）：

**可复用配方（并列多方案，均为借鉴）：**
- **方案 A（#8 怼脸活人感，博主原发提示词）**：
  ```
  正向：真实相机拍摄视频，第一视角怼脸大特写，年轻东亚女生，乌黑蓬松黑长直发，细碎凌乱胎毛刘海，少量碎发丝散落额头，清淡伪素颜，淡橘调哑光唇色，干净通透原生皮肤，保留细微皮肤肌理，细腻瞳孔高光，眼球里环境倒影清晰，眼神灵动，嘴唇微微嘟起，微表情细腻自然，柔和漫射自然光，面部光影过渡柔和，超高细节，写实人像，头部轻微自然微动，眼珠自然转动，真实呼吸感
  负面：卡通/动漫/塑料假皮肤/过度磨皮/浓妆/表情僵硬/AI崩坏/面部闪烁/五官抖动错乱
  ```
- **方案 B（#6 姜颜·克制情绪特写，反推）**：`中近景，人物神情克制悲怆，胡须碎发自然，眼神低垂/冷峻，侧逆光勾轮廓，低饱和青灰调，浅景深，皮肤保留纹理不过度磨皮，35mm 胶片轻微颗粒`。
- **方案 C（#1 情绪感人像公式，反推）**：`35mm 胶片质感，人脸大特写，逆光侧光，浅景深，强烈而克制的情绪（含泪/压抑），微表情细腻，眼神有光，皮肤保留纹理，冷灰调低饱和`。
- **方案 D（#14 李一帆·不靠抽卡锁角色，并列）**：先准备一张（组）角色参考图上传锁定，再图生视频，**不靠空提示词反复抽卡**。一致性两条路线并列，按需求选：
  - **角色资产驱动**（#14，评论指 libtv 人物多参图、博主自称"已淘汰 ComfyUI"）：单角色多参图 + 表情/质感调节，偏"一个数字演员可复用贯穿多条广告"。
  - **素材库驱动**（#1 Seedance 2.5）：一次喂 30图+10视频+10音频（上限 50），偏"产品+场景大量参考混排"。
  - 选择倾向：一个模特贯穿多条广告 → 角色资产驱动更省；产品+多场景参考混排 → 素材库驱动容量更合适。

**"会演"（表情不僵硬）实现三手段（#14，逐条标来源）：**
1. **参考图定脸**（[已查证画面]）：上传参考图锁定角色长相，跨场景不"千篇一脸"。
2. **提示词写具体微表情**（[已查证画面]+[分析推断]）：把情绪写成具体动作（"大笑露齿/冷峻侧视/松弛微笑"），而非笼统的"自然表情"；多人同框可"全员一起变表情"。
3. **表情/动作参考驱动**（[分析推断]）：可能用动作/表情参考驱动，本片未展示提示词原文，待实测。
> 质感真实三手段：保留皮肤纹理/胡茬、浅景深、冷调电影感打光，避免过度磨皮（与 #8/#6"非塑料感"互证）。

### 簇 2｜胶片感 / 电影质感（#9 后期三件套 + 柯达胶片系）

**跨视频关键经验汇总：**
- 胶片感＝**后期三件套**：降噪（暗部颗粒控制）＋调色（低饱和偏暖）＋模糊边缘（柔化 AI 边缘）→ 减少 AI 感（#9 SansanYe）。
- 胶片感物理词：低饱和、暖色偏、暗部颗粒、边缘柔化、高光柔和。
- 柯达胶片系选型（batch1 A3，[已查证]章节要点）：PRO400＝人像万能、真实肤色、低饱和暖调、细腻颗粒；TMAXP3200＝黑白高对比、粗粝颗粒、暗光爆发力、故事张力。
- 模型分工（#9，博主一方说法）：Seedance＝提示词核心（统一质感/复杂动作）；Keling 可灵＝参考图核心（分镜图/高性价比，风景图用它）。

**可复用配方（并列多方案）：**
- **方案 A（#9 提示词模板）**：`摄影机参数（镜头焦段/光圈/快门）+ 画面质感（胶片/颗粒/色偏）+ 分镜（景别/运镜）+ 人物设定 + 场景（年代/地点/时间）`。
- **方案 B（柯达 PRO400 温柔人像）**：人像珠宝片 → 低饱和暖调 + 细腻颗粒 + 真实肤色还原。
- **方案 C（TMAXP3200 黑白张力）**：故事张力/悲情段 → 高对比 + 粗粝颗粒（与姜颜悲情段互证）。

### 簇 3｜分镜 / 镜头语言（#5 衔接三法 + #7 34秒34镜头 + #6 姜颜叙事结构）

**跨视频关键经验汇总：**
- **分镜衔接三法（#5 Insight AI，核心交付物）**：① 动作衔接（上镜尾帧动作↔下镜首帧承接）；② 文本/旁白衔接（用一句旁白缝合两个场景）；③ 景别切分（相邻镜头换景别，不连排同景别硬切）。
- **分镜拆解框架（#5）**：先定场景图（在哪）→ 再定人物多视图+角色卡（是谁）→ 逐镜写"环境+主体动作"→ 每镜标注景别/机位。每张分镜图写全"环境+动作"以**降低抽卡率**。
- **密度参考（#7 艺谋学长）**：34 秒=34 镜＝**平均 1.0 秒/镜**（高密度快剪，接近 MV/广告节奏）；景别在"特写紧细节↔全景场面↔中景动作"间交替跳动；动作戏用**动作顺接（cut on action）硬切**，掩盖 AI 单镜瑕疵。
- **姜颜叙事结构（#6，四幕）**：动作 hook（追击）→ 穿越反差（回忆）→ **历史悲情高潮（嵇康抚琴）** → 落脚日常收束（客栈）。镜头密度随情绪走：动作段密、悲情段疏、收束段缓——**疏密对比本身就是情绪工具**。

**可复用配方（并列多方案）：**
- **方案 A（#5 广告分镜表骨架，可改造）**：① 特写旧项链 → ② 中景师傅持钻 → ③ 特写蓝宝石嵌入 → ④ 近景模特佩戴转头 → ⑤ 全景佩戴者微笑。相邻镜换景别；改款前后用动作衔接（摘下→戴上手部承接）或旁白缝合（"三个月后，同一条项链换了灵魂"）。
- **方案 B（#7 快剪藏拙）**：1–2 秒/镜快剪（宝石火彩特写→佩戴中景→柜台全景），景别交替，切点对齐 BGM 重拍。
- **方案 C（#6 疏密节奏）**：产品大特写段放慢（学抚琴手部特写），动作/展示段加快，情绪峰值（戴上身那一刻）切音乐高潮。

**来源标注：** [已查证] 衔接三法/分镜框架（#5 章节要点）；[博主一方说法] "1 秒/镜"（#7 标题主张）；[分析推断] 姜颜四幕情绪弧线。
**可反哺 SOP 章节：** 广告叙事与故事塑造 SOP（分镜章节）；分镜/剪辑相关。

### 簇 4｜提示词框架（#11 四要素：提示词+图形引导+模型能力+审美）

**跨视频关键经验汇总：**
- **四要素框架（#11，博主原话已查证）**：`AI艺术(影视) = 提示词 + 图形引导 + 模型能力 + 审美`——"提示词后面每个都比提示词重要，是越来越重要的递进关系"。
- "一张图的信息量远远超过提示词"；"文生提示词只会越来越不重要"。
- 三方互证：#11（框架）+ #12（深度参考解耦）+ #10（白模解耦）+ batch1 A12（创觉珠宝"学 AI 要学背后的光线/色彩/构图"）→ **图形引导 > 提示词**。
- 与项目既有约束互证：项目 AGENTS 已规定"有实物/方案图必须图生图/图生视频，不文生图重画"。

**可复用结论（并列多方案）：**
- **方案 A（图形引导优先）**：有蓝宝石项链实物图/方案图 → 必须图生图/图生视频，不追求纯文字重画。
- **方案 B（心动图反推提示词，batch1 A1）**：找一张满意的参考图 → 让 AI 反推提示词 → 再生成。
- **方案 C（四要素自觉分配精力）**：提示词只占一部分精力，更多投在"选参考图（图形引导）、选对模型、练审美判断"上。

### 簇 5｜运镜参考 / 动作捕捉（#12 深度参考解耦 + #10 白模驱动）

**跨视频关键经验汇总：**
- **运动/空间与画面解耦**是复杂运镜的正解，三方互证：
  - #10 小朱朱白模：白模视频提供**纯运动轨迹**，成片生成时不被原角色/原场景污染；GPT 可生成白模 → 截首帧 → 图生视频"直接生成"，少量积分。
  - #12 深度动作捕捉：直接拿原视频当参考，复杂镜头（环绕/转身）人物走位构图容易跑；**先变"干净的深度参考"只留运镜/动作/空间关系，效果反而更好**。
  - batch1 A7 LibTV：上传视频→深度动作捕捉→AI 自动转白模视频→上传角色图/场景图→生成。
- **关键教训（#12）**：参考素材不是越完整越好——喂太满反而锁死构图。

**可复用配方（并列多方案）：**
- **方案 A（白模驱动，#10）**：生成白模运镜视频 → 截首帧定画面基准 → 图生视频直接生成。适合珠宝环绕/推近运镜。
- **方案 B（深度参考解耦，#12）**：导入原片 → 提取深度视频（只留运镜/走位）→ 截帧 → 换画面生成。
- **方案 C（首尾帧+九宫格，batch1 A12 创觉珠宝）**：首帧=九宫格分镜图、尾帧=最终画面，Seedance 2.5 首尾帧模式生成珠宝展示片。

### 簇 6｜剪辑自动化（#2 ChatCut+Codex 工作流、分镜表结构）

**跨视频关键经验汇总：**
- **自动化剪辑范式（#2 李一帆，画面实证）**：对话式——和 Codex 聊需求（产品/风格/音乐/旁白），让它调用 ChatCut；Codex 自动出**分镜表**（时间轴×内容×景别×旁白×BGM 编号）→ ChatCut 按表自动铺素材/配乐/旁白/字幕/Logo 动画 → 缺镜头回对话补生成。整套流程可**存成 Skill 复用**。
- **人工介入点**：人只做"期初说清需求"+"期末验收"两件事。
- **成本权衡**：ChatCut 收费、评论反馈"不便宜"；建议先用剪映/免费链路跑通一条样片验证分镜表，再决定是否为量产上付费自动化。
- 大场景/长镜头策略（#5 + #1 Seedance 2.5）：一段生不下来就**多段生成 + 剪辑软件拼接**，不追求一条直出。

### 簇 7｜模型选型（#1 Seedance 2.5 玩法 + #4 MiniMax H3 云端优先 + #3 Opus 5.5 无需跟进）

**跨视频关键经验汇总：**
- **Seedance 2.5 已实测玩法（#1 Xuan酱）**：
  - 主体参考：一次喂 **30 图+10 视频+10 音频**（从 12 升到 50），锁人物/产品一致性；

- **三档流水线（#1 + #15 补全，并列分阶段）**：
  ```
  ① 2.0 Fast 试分镜（淘汰废方案，镜头/剧本/风格未定阶段）
    → ② 480P 2.5 + Flova 超分（门店屏/抖音信息流量产，≈0.2 元/秒，已定片要 2.5 表演但不需原生高分辨率）

  ```

- **Opus 5.5（#3）**：是 Claude 编程/推理 LLM，**不是视频生成模型，不构成对即梦/可灵工具栈的替代，无需跟进**；仅"一句话生成 2 分钟带配乐音效的 HTML 沙画动画"对科普型短视频有参考价值。

### 簇 8｜工具选型与成本（FlovaAI 候选判断 + 480p+超分路线 + #1 成本实测）

> FlovaAI 相关结论均引用 `flovaa_platform_research.md`（2026-10-06 专项调研）。

**跨视频关键经验汇总：**
- **FlovaAI 候选判断（flovaa_platform_research，[已查证为主]）**：
  - 定位＝**低成本试片/样片验证备选，不进自动化主链路**；不签订阅、不年付。
  - **无传统 REST API**；程序化接入靠 **Flova CLI**（可被 Codex/Claude Code 桥接，项目级粗粒度，非单镜头参数级）。
  - 价格锚点：818 促销期 Seedance 2.5 低至 0.175–0.23 元/秒（480P/720P），约官方火山方舟刊例（≈0.67 元/秒）的 1/3–1/4；**但 818 已于 9/17 结束，当前（10/6）价需登录确认**。
  - 主链路仍是火山方舟 Seedance/Seedream REST API；Flova 定位"UI 端低成本创意验证+成片参考"。
  - **候选判断限定期**：随平台版本/价格政策变化，需按实测与预算复核。
- **480p+超分路线（batch1 A12 + flovaa 互证）**：分辨率不是画面质感核心，**480p 生成+4K 超分 Skill**也能高质感（创觉珠宝本期 80% 画面是 480p+4K 超分）。Flova 的"4K"大概率是低分辨率生成+超分 Skill，非原生 4K。
- **#1 成本实测（评论区观众）**：30s 720P≈3 元/条；10s 可用片≈1000 积分；"2.5 出来后 2.0 降智了"。

**可复用结论（并列多方案）：**
- **方案 A（低成本试片）**：Flova 注册送 300 积分（≈$3）跑 2–3 个 10s 480P 样片验证风格 → 满意后小额充值走 720P → 终版再定是否超分。不年付、不大额充。
- **方案 B（自动化主链路）**：火山方舟 REST API 逐镜头参数可控、可批量并发——精修/量产走这条。
- **方案 C（成本最优画质）**：480p/720p 生成 + 4K 超分，不为原生 4K 付溢价。
- **方案 D（#15 睿叔叔·低成本 4K 档位，并列）**：Seedance 2.5 **480P 生成 → Flova 内置「视频超清」超分 1080P/2K/4K + 高质量补帧 + 30fps**，本质是"低分辨率生成+AI 超分+补帧提帧率"，**非原生 4K**。博主口径合计 ≈ **0.2 元/秒**（480P 生成 0.17 元/秒[年费折算] + 超分几分钱），与 flovaa 818 促销 0.175 元/秒互证；对照原生高分辨率出片 ≈ 2.5 元/秒。
  - **适用（远观/量场景）**：门店循环播放屏（观看 1–3 米、循环耗片大）、抖音种草信息流（小屏刷看、停留 3–5 秒）、内部试片。
  - **不适用（近看/质场景）**：蓝宝石微距精修、客户交付片——超分只插值放大、不生成新细节，宝石火彩/镶口/金属反光的微观细节会糊；博主本人评论区承认"头占画面 1/5、图 2K，得 1080p+ 才够精细"。
  - **判断依据＝观看距离 × 停留时长 × 是否交付**：远观/短停留/内部使用→大胆用；近看/长停留/交付客户→别省。4 项自检（链条/五官/手部/吊坠居中）也应在 720P/1080P 原生档做，别在 480P 超分底版上做（会"假装清晰"掩盖变形）。

### 簇 9｜音频配方主题簇（三层混搭[姜颜标杆] / 旁白即转场[#5] / 口播让位[#4/#3] / 事件触发拟音[姜颜] / 路线 A/B 判定）

**跨视频关键经验汇总：**

1. **三层混搭（#6 姜颜，音频标杆，用户认可样本）**：
   - 古风弦乐（旋律层/时代感）+ 低音铺底（氛围厚度层/史诗感）+ 人声旁白（叙事层）；
   - 频段分层互不掩蔽：人声最前（叙事优先）＞弦乐居中 ＞低音垫底；人声停顿处弦乐补位，三层轮流"说话"。
   - 情绪随剧情消长：动作段低音加厚 → 悲情段弦乐 solo → 收束段转暖。

2. **旁白即转场（#5 Insight AI）**：场景切换点用一句描述性旁白缝合两个场景（"切到下一个场景了，让整座山缓缓落进眼里"），观众耳朵先被告知"要换场景"，转场不突兀。旁白本身就是教具。

3. **口播让位 / 三段式（#4 MiniMax H3 + #3 Opus 5.5）**：
   - 教程/资讯类内容＝**人声为绝对主声道，BGM 压到最低或无**；
   - #4 三段式：hook 用"带人声/环境音的 AI 成片"先声夺人 → 教程段零 BGM 口播 → 成片展示段**声音留白让画面说话**；
   - #3 口播优先型：BGM 让位原则，口播视频 BGM 压到人声不可闻。

4. **事件触发拟音（#6 姜颜，详见簇 10）**。

5. **路线 A/B 判定汇总**：
   - **路线 B（分层生成+剪辑混音）**：#6 姜颜（三层可分离）、#5（口播轨+环境音轨分层）、#4（hook 成片音+教程口播分层）、#2（ChatCut 曲库选曲+人声分层）、**#13 姜颜东晋·上篇（延续路线 B，三层可分离；本集低音铺底占比更大、弦乐更克制，比魏晋篇更冷更荒）**。
   - **路线 A（整段一次生成/口播单轨）**：#3 Opus 5.5（人声主导、BGM 弱垫底，单轨）。
   - **路线 B 变体（借现成曲库）**：#1 Seedance 玩法（情绪段直接借《傲慢与偏见》现成电影配乐背书高级感——注意商用版权风险，需换可商用同质感钢琴曲）。

### 簇 10｜声音细节触发机制经验簇（姜颜：环境变化触发环境音 / 剧情变化触发人声微表情）

**跨视频关键经验汇总：**
- **核心命题（#6 用户听感原话）**：声音细节不是背景噪音，而是**被环境变化、剧情变化精确触发**——"板凳的声音、人说话时哼气的语气、叹气声音、轻笑声音，都是基于环境的变化、剧情的变化而触发的"。
- **触发逻辑（两条）**：
  - **环境变化 → 环境音**：场景一切换（土路→庭院→客栈），空间混响与环境底噪随之变化（室内木质空间干声/回声）；
  - **剧情变化 → 人声微表情**：角色到情绪节点（发愁→叹气、喜剧反转→轻笑、对话→哼气），微反应人声才出现；**没有画面依据的声音不出现**。
- 细节清单（#6 音频专项，画面已查证）：板凳/木桌挪动声（搬桌帧）、叹气（发愁节点）、哼气（对话镜头）、轻笑（喜剧反转点）。

**可复用提示词挂载模板（借鉴选项，写在每镜提示词末尾随画面事件挂载）：**
```
[镜头动作描述] + (触发式拟音)
· 人物落座/挪凳镜头 → 句尾加：(木凳挪动摩擦声)
· 人物发愁/低头 → 句尾加：{角色轻叹一口气}
· 人物对话 → 句尾加：(语气带自然哼气，非平铺直叙)
· 喜剧反转镜头 → 句尾加：{一声无奈的轻笑}
· 场景切换到室内 → 标注：(室内木质空间混响，环境底噪收干)
```
**珠宝片迁移**：手指抚过旧项链 → (细微金属/宝石摩擦声)；戴上身那一刻 → (一声释然的轻呼吸)；柜台展示段 → (室内干净空间混响)。复现需实测。

### 簇 11｜画面层事件触发（#13 姜颜东晋·上篇）——与簇 10「声音触发」同一机制的两个侧面

> **定位说明**：簇 10 讲"声音由剧情/环境事件触发"，本簇讲"画面意象/特效也由剧情节点触发"——**二者是同一"事件触发"机制在音频层与画面层的两个侧面**：声音由事件触发、画面意象也由剧情节点触发。原则一致：没有画面依据的声音/意象不出现，每个细节都能指回一个剧情/画面触发点。
> 来源：7689176095253482767_姜颜_东晋上篇_effect_analysis.md（[已查证帧]/[用户观察]/[分析推断] 逐条标注）。

**三个电影级画面细节 · 机制分析：**

1. **毛笔写字实时显字（书写戏成立）**
   - 画面依据：08:43 群贤围案、09:04 执笔特写（书写戏成立）；用户观察"笔尖落下处实时出现墨迹"。
   - 机制推断（[分析推断]）：最可能是**后期逐帧合成/对齐**——AI 一次生成难保证笔顺正确+墨迹随笔尖走；次选提示词强约束+模型动作同步，但仍常需后期修字。
   - 可复用写法：`{毛笔落纸处墨迹逐画显现}`（并标注"实时显字需后期逐帧对齐/修字，别指望模型一次生成"）。

2. **电影肃杀之气（氛围统一手法）**
   - 公式（[分析推断]）：**低饱和青灰土黄冷色 + 漫射阴天灰光 + 大远景空镜留白 + 废墟道具（尸阵/断旗/破亭）+ 慢节奏收束**；氛围统一靠**提示词+调色**。与"高级感"同源，但情绪指向"苍凉/杀伐"而非轻奢。

3. **场景突变花朵（情绪钩子技法）**
   - 用户观察：部分场景突然出现花朵（瞬间意象插入）。
   - 机制推断（[分析推断]）：在悲怆节点（告别/死亡/追忆）由**剪辑层插入 1–2 秒意象空镜**（落花/花枝），给肃杀主线一个情绪呼吸口、以美衬亡；多以镜头切（cutaway）而非特效叠加实现。

**可复用写法三件套（逐条标实现来源）：**

| 写法 | 模板 | 何时用 | 实现来源 |
|---|---|---|---|
| 关键动作帧同步特效 | `{毛笔落纸处墨迹逐画显现}` | 书写/手部关键动作镜头 | 多为后期逐帧合成 [分析推断] |
| 情绪节点插入意象空镜 | 悲怆点后切 1–2s 落花/花枝空镜，再切回主线 | 告别/死亡/追忆转场 | 剪辑层插入 [分析推断] |

**珠宝片迁移（借鉴，只借手法不借情绪）**：蓝宝石本就冷调，可迁移"低饱和+空镜留白+氛围统一"为珠宝高级冷感；蓝宝石特写不必铺满，可在情绪节点（戴上身/擦拭/凝视）插入 1–2 秒意象空镜（宝石火彩光斑），与音频卡点同构；若要"刻字/Logo 实时显现"这类高难效果，预留后期逐帧合成预算。
