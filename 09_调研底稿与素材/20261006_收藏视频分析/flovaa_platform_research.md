## 一、结论先行（TL;DR）

1. **FlovaAI 是什么**：雨舟科技（深圳）有限公司、郭列（脸萌/FaceU 激萌创始人，后在字节孵化轻颜/剪映/醒图）2025 年再创业的**视频 Agent 平台**，红杉/IDG/云九两轮累计超 8000 万美元融资。本质是**上游视频模型的聚合分发 + Skill 化工作流封装**——自己不训练视频大模型，接入 Seedance 2.5 满血版/MiniMax H3/可灵 Kling 3.0 Omni/Wan 3.0/Nano Banana/GPT Image 2/Suno 等，用"Agent + Skill"把剧本→分镜→生图→生视频→剪辑→配乐串成一条对话式流水线。【已查证：Founder Park 专访 + 官网 + 企查查】
2. **价格锚点**：新注册送 300 积分（≈$3）；视频按秒计费，2026 年 8–9 月价格战期间 Seedance 2.5 低至 **0.175–0.23 元/秒**（480P/720P 促销价），约为官方火山方舟 API 刊例（≈0.67 元/秒）的 1/3–1/4。**注意：818 狂欢月（8/18–9/17）已结束，当前（10/6）刊例价需登录后确认，下文促销数字均为历史锚点，非常态价。**
3. **API 结论（关键）**：**未发现传统 REST/开放平台 API**（flova.tv/pricing、docs.flova.tv 均不可达，无开发者门户）。程序化接入靠 **Flova CLI**——可被 Codex / Claude Code / WorkBuddy 等外部编程 Agent 调用，完成"建项目→排故事板→跑素材→导出"。这与 LibTV CLI 同属"CLI 桥接外部 Agent"路线，**不是火山方舟那种可裸写 SDK 的 REST API**，自动化能力上限取决于 Flova CLI 实际暴露的命令集（需登录后实测）。
4. **是否纳入候选**：**建议纳入"低成本试片/样片验证"备选，不进自动化主链路**。理由：① 促销期单价确实低，适合珠宝广告"抽卡试片"；② Skill 生态（商业广告/产品展示类）与珠宝宣传片对位；③ 但无官方 REST API、促销价不可持续、平台成立不到一年、上游模型厂商（字节/MiniMax）亲自下场做 Agent 工作台，聚合平台存在被"去中间化"风险。我方自动化主通道仍应是**火山方舟 Seedance/Seedream REST API**（个人实名、SDK 现成、价同量级），Flova 定位为"UI 端低成本创意验证 + 成片参考"。

### 3.2 Skill（工作流商店）生态

- 官网首页 Featured Skills 分类：Trending / Drama（短剧）/ Commercial（商业广告）/ Music·MV；站内 Skill 库分 12+ 类：新手必用/大师美学/剧情短片/商业广告/动漫游戏/短剧/微电影/MV/**产品展示**/平面设计/生活 Vlog/工具增强。【已查证：腾讯新闻 2026-08-15 Skill 库截图】
- 与珠宝宣传片直接对位的官方 Skill：
  - **Product Promo Video**（产品宣传视频，Nano Banana + Seedance 2.5 @480p）
  - **New Product Launch Commercial**（新品上市广告，GPT Image 2 + Seedance 2.5 @480p）
  - **E-commerce Product Visual Suite**（电商白底图/主图/详情图，默认不出视频除非要求）
  - **Brand Logo Scene Kit**（Logo 实景六场景 + Kling 3.0 Omni 出 3–5s 竖版）
  - **Unboxing & First-Impressions Product Ads**（开箱/横评/对比，20 类目含美妆个护）
  - **Fashion Showcase Short**（服装/走秀/Lookbook，围绕廓形/面料/佩戴姿势）
- Skill 以 Markdown 文件定义，内含流程规划、镜头语言、模型调用顺序、提示词规范；用户可"新建 Skill"自定义并发布，平台负责审核 bug。【已查证：Skill MD 截图 + 郭列专访】
- **与基线 A4 的互证**：抖音博主 AIGC-Domy（豆妹）所讲"邪修平价超分 4K"即 Flova Skill 商店里的超分类 Skill——**"低成本提级 4K"是 Skill 工作流而非 Flova 自研超分模型**，本质是低分辨率生成 + 超分 Skill 提价，与基线 A12"480p+4K 超分"路线同构。【博主一方说法（A4 原视频）+ 本调研 Skill 生态交叉】

### 3.3 时长、分辨率与功能边界

- 单条视频时长：随模型，Seedance 2.5 最长 **30s**（与火山方舟 API 档位 [4,30]s 一致）；多镜头由 Agent 拆成 8–N 个分镜再时间线组装。【已查证：ZAKER 实测 2 分钟短片 = 8 个分镜】
- 分辨率：UI 预览栏可见"480 / 720 / HD / 4K"按钮；**4K 是否为 Seedance 2.5 原生 4K 输出，还是"低分辨率生成+超分 Skill"提级，官方页面未逐字说明**——结合基线 A2/A4 博主口径"10 秒 4K≈2 块多"，**大概率是后者（480/720 生成 + 超分提级），与官方 Seedance 2.5 API 仅支持 480p/720p/1080p（无原生 4K）的口径互证**。【已查证官方模型档位 + 博主一方说法交叉；4K 具体路径标注"未经核实"】
- 在线剪辑：故事板镜头拖拽进时间线做粗剪；不替代剪映精剪。【已查证】
- 人脸/口播：Seedance 2.5 支持全模态参考与人物一致性；**真人人脸/口播合规边界未见 Flova 官方条款**，与基线工具选型参考中"Seedance 2.0 系列不支持真人人脸正脸视频、2.5 放开"的口径需实测确认。【未经核实】

## 五、API / 程序化接入（决定能否进我方自动化链路）

### 5.1 结论

| 通道 | 状态 | 说明 |
|---|---|---|
| 传统 REST API / OpenAPI | **未发现** | flova.tv/pricing 返回死链；docs.flova.tv 无法解析；官网与全部报道均无"开放平台/开发者门户/API Key/Webhook"字样。**不提供火山方舟那种 `POST /contents/generations/tasks` 式裸 REST。**【已查证：官网抓取 + 多关键词检索】 |
| **Flova CLI** | **存在，可外部 Agent 桥接** | 官方对外发布 CLI，可被 Codex、Claude Code、WorkBuddy 等外部编程 Agent 调用，完成"创建项目→推进故事板→跑素材→查看→导出"。实测者称"全程没开网页，用 Claude Code 跑通"。【已查证：腾讯新闻 2026-08-15 + 搜狐 2026-08-10 + 掘金 2026-08-09 + 今日头条 2026-08-14】 |
| CLI 具体安装命令/包名/命令清单 | **未经核实** | 公开报道只说"有 CLI、能被 Codex/Claude Code 接"，**未公开 npm 包名、安装命令、命令 schema**（对比 LibTV CLI 1.1.3 有公开下载包与 11 命令文档，Flova CLI 文档透明度明显更低）。需登录 flova.tv 后在站内获取。 |
| Webhook/异步回调/批量并发 | **未见公开** | 无开放文档，无法确认是否支持。 |

### 5.2 与我方自动化链路的关系

- 我方既定自动化主通道 = **火山方舟 Seedream/Seedance REST API**（个人实名、SDK 现成、异步 callback、可批量并发）。Flova **不替代这条通道**。
- Flova CLI 的定位类似 LibTV CLI：是"让编程 Agent 帮你在 Flova 网页工作台上建项目"的桥，**粒度比 REST API 粗**（项目级/故事板级，不是单镜头参数级），且依赖 Flova 服务端 Agent 调度，稳定性/SLA 无公开承诺。
- 若未来想用 Flova，自动化路径是：**在豆包/Codex/Claude Code 里装 Flova CLI → 用自然语言把珠宝剧本推给 Flova → Flova Agent 自动拆镜跑素材 → CLI 导出成片**。这比"裸 REST 逐镜头提交"更省提示词功夫，但**失去对单镜头参数（分辨率/时长/首尾帧）的精确控制**，且全程消耗 Flova 积分。

## 七、是否值得纳入候选：结论 + 理由 + 风险

### 7.1 结论

**（2026-10-06 调研时点的候选判断，并列参考选项之一，非唯一标准断言）**

**建议定位为"观察 + 低成本试片"候选，暂不进自动化主链路；不签订阅、不年付。** 优先级参考序（火山方舟 REST 为主通道 → 即梦 App UI 为现状主力 → LibTV CLI 为批量进阶 → Flova/Pavo/小云雀AI 同属"低成本创意验证层"）仅为本项目当前约束下的倾向，**不是排他结论**——导演风格与审美标准因人因片而异，团队可按实际出片效果与预算自由调整各工具权重。**本候选判断随平台版本/价格政策变化，需按实际测试与预算复核。**

### 7.2 理由

1. **价格确实便宜（促销期）**：0.175–0.23 元/秒 vs 火山方舟 0.67 元/秒 vs 即梦 App 积分折合约 1.5 元/秒（10s≈15 元）。珠宝"项链改款"宣传片要反复抽卡选镜头，试片成本压到 1/3 是实在收益。
2. **Skill 与珠宝商业广告高度对位**：官网直接有 Product Promo Video / New Product Launch / E-commerce Visual Suite / Unboxing / Fashion Showcase 五个商业广告 Skill，上传产品图即可跑，比从零写提示词快。
3. **姜颜视频实证**：用户评价"效果特别棒"的魏晋篇，证明 Flova 在"古风/审美向连续叙事"上出片质量过关（与基线 A4 博主口碑一致）。
4. **Agent 编排省人**：剧本→分镜→资产→镜头→配乐一条对话流，对不懂提示词的门店同事友好；"评论修改"局部改镜头减少重抽浪费。
5. **但自动化主链路不能押它**：无裸 REST、CLI 文档不公开、按项目粒度桥接，无法做我方规划的"脚本批量提交+回调落地转存"。

## 八、对线下珠宝门店的适配建议

### 8.1 试片成本测算（促销口径 vs 保守口径）

- 一条 30s 蓝宝石项链宣传片 ≈ 8 个分镜 × 平均 4s = 32s 生成量。
- 促销口径（0.2 元/秒）：一条成片理想态 ≈ 6.4 元；按珠宝抽卡经验（5–8 倍废片率），一条能交付的片 ≈ **30–50 元**。
- 保守口径（按 0.5 元/秒）：同流程 ≈ **80–130 元**。
- 对比：即梦 App 积分折合约 1.5 元/秒，同流程 150–260 元；火山方舟 REST 约 0.67 元/秒但无 Agent 编排，提示词成本另计。
- **建议门店试片路径**：先用 Flova 注册送的 300 积分（≈免费）跑 2–3 个 10s 480P 样片验证风格 → 满意后充值小额（百元级）走 720P → 终版再决定是否上超分 Skill。**不要年付、不要一次充大额。**

### 8.2 出片质量建议

- 珠宝产品微距（蓝宝石刻面、镶口、链条细节）：用官网 **E-commerce Product Visual Suite** 出静帧白底图，再用 Product Promo Video Skill 串成动态；**不要直接文生视频重画产品**（呼应基线 A5"图形引导>提示词"）。
- 佩戴镜头：上传真实项链实拍图 + 模特参考图，走 Nano Banana（生图一致性好）→ Seedance 2.5 图生视频；480P 先试，定调后 720P，超分 Skill 提质感（与基线 A12"480p+4K 超分"一致）。
- 姜颜魏晋篇那种"审美向连续叙事"适合做品牌故事/展厅氛围片，不适合做"产品改款对比"硬广——硬广仍走即梦/火山方舟精修链路。

### 8.3 自动化可能性

- **短期（门店同事能用）**：纯 Web UI，自然语言对话，手机浏览器也能开（官网称移动端数据同步），无需写代码——适合门店店员自己跑样片发客户。
- **中期（我方自动化）**：观察 Flova CLI 是否开放公开文档；若开放，可在 Codex/豆包里把"客户改款需求→剧本→Flova 出片"串成半自动流水线；但**精确控镜头/批量并发仍走火山方舟 REST**。
- **不做**：不基于 Flova 做无人值守批量生产（无 webhook、无批量 API、抽卡仍需人审）。
