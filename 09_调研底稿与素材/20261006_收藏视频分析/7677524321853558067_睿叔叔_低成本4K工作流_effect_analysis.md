## 六、核心问题解答（用户最关心的"什么场景用"）

### 6.1 完整链路拆解与成本测算

**链路（已查证 UI）**：
```
Seedance 2.5 以 480P 生成初片（廉价档）
   → Flova「视频超清」弹窗选 4K（或 2K/1080P）
   → 开「高质量补帧」+ 30fps
   → 出片 = 视觉上的"4K 视频"
```

**它本质不是"原生 4K"，是"低分辨率生成 + AI 超分 + 补帧提帧率"**——与我方基线 A12（创觉珠宝 AI："480p+4K 超分也能做高质感，本期 80% 画面是 480p+4K 超分"）、A4（Flova 邪修平价超分 4K）**完全同一条路线**，本片是该路线在 Flova 站内的手把手操作实证。

**成本测算（博主口径 vs 我方基线对照）**：

| 环节 | 单价（本片口径） | 来源档 |
|---|---|---|
| Seedance 2.5 **480P 生成**（Flova 年费会员折算） | **0.17 元/秒** | 博主评论区自述（年费折算） |
| Flova「视频超清」超分到 4K + 补帧 | **"再加几分钱"**（约 0.03–0.05 元/秒，估算） | 博主口播"再加个几分钱" |
| **合计** | **≈ 0.2+ 元/秒（"2 毛多一点"）** | 本片字幕 |
| 对照：博主称直接出高分辨率 | **2.5 元/秒**（"一秒钟 2 块 5"） | 本片字幕 |

**与我方成本基线对照（flovaa_platform_research.md）**：
- Flova 818 促销 480P = **0.175 元/秒** ← 博主 0.17 元/秒（年费折算）**高度吻合**，互证促销价真实可达。
- 基线 A2 博主"10s 4K ≈ 2 块多" ← 本片 0.2 元/秒 × 10s = **2 元多，完全互证**。
- 基线 A2 评论"720p 30s = 3 块钱"= 0.1 元/秒，比本片 480P 还低（可能不同促销/档位），方向一致。
- 火山方舟官方刊例 ≈ **0.67 元/秒**（2.5）；即梦 App 高级会员折合约 **2.5–2.8 元/秒**（780 积分/30s ≈ 84 元）——**博主说的"2 块 5 一秒钟"正是即梦 App 积分折算价，口径成立**。
- **"一毛钱/秒"是否成立**：标题是营销修辞，本片自己字幕改口"2 毛多一点"；严格说 **480P 生成 0.17 元/秒 + 超分几分钱 ≈ 0.2 元/秒**，"一毛钱"是四舍五入到"几毛钱"量级的说法，**不是精确 0.1 元/秒**。

### 6.2 场景适用性判断（核心交付：我方 5 个业务场景逐一定位）

| 我方场景 | 建议用这套"480P+超分"省钱工作流？ | 判断依据 |
|---|---|---|
| **① 项链蓝宝改款·终版精修片** | ❌ **不建议做终版**，可用于前期试片 | 终版要交付客户，蓝宝石火彩/镶口/金属反光的**微观细节**是转化核心；博主本人评论区已承认"头占画面 1/5、图 2K，得 1080p+ 才够精细"——480P 原生细节不足，超分只是"插值放大+补帧"，不生成新细节，微距产品细节会糊。终版仍走高分辨率原生。 |
| **② 模特版视频（锁骨+侧脸佩戴，4 项自检）** | ⚠️ **折中**：试片/选模特/选服装用 480P+超分；定版镜头走原生高分辨率 | 佩戴中景/侧脸对微观细节要求低于产品微距，超分收益可接受；但 4 项自检（链条变形/五官/手部/吊坠居中）要看清——480P 起手会让链条与手部细节模糊，**自检反而变难**。模特一致性镜头可 720P 原生，不必硬上 4K 超分。 |
| **③ 线下门店宣传（循环播放屏）** | ✅ **适合** | 门店屏观看距离 1–3 米、循环播放、观众无意细抠像素；480P+超分的"电影感"在大屏远观完全够用，且循环屏耗片量大，省钱=省运营成本。 |
| **④ 抖音种草（信息流口播/展示片）** | ✅ **非常适合** | 抖音信息流默认 720P 起播、用户手机小屏刷看、停留 3–5 秒即划走；480P+超分 + 30fps 补帧在信息流里观感与原生 4K 拉不开差距，但成本差 10 倍。**这是本工作流性价比最高的场景。** |
| **⑤ 客户交付（定制成品视频）** | ❌ **不建议** | 客户对"定制"的预期=精品；480P 底版超分在大屏/投影/客户手机放大细看时易露馅（边缘软化、纹理插值），交付风险高。客户版走高分辨率原生。 |

**一句话结论**：这套工作流是**"量场景"和"远观场景"的省钱工具**，不是"质场景"的替代方案。判断依据=**观看距离 × 停留时长 × 是否要交付**：远观/短停留/内部使用→大胆用；近看/长停留/交付客户→别省。

### 6.3 与"2.0 Fast 粗剪 → 2.5 精修"策略的对比定位

我方既有策略（工具选型参考）：Seedance 2.0 Fast 粗剪试片（10s≈140 积分≈15 元）→ 选定方向后 2.5 精修。本片工作流与之**并列、可互补，不替代**：

| 维度 | 2.0 Fast 粗剪→2.5 精修 | 本片"480P 2.5 + 超分" |
|---|---|---|
| 省钱发生在哪一环 | **换模型**：粗剪用便宜模型（2.0 Fast），精修才上 2.5 | **降分辨率**：直接用 2.5 但只出 480P，再超分补清晰度 |
| 画质天花板 | 粗剪天花板=2.0 Fast（较低）；精修=2.5 原生高分辨率（高） | 全程=2.5 的运镜/表演/一致性（高），但清晰度上限=480P 底版 |
| 适合 | 还在试"镜头/剧本/风格"阶段，要快速淘汰废方案 | 已定片、要"2.5 的表演 + 便宜的价格 + 能看的清晰度" |
| 珠宝映射 | 试 5 个不同分镜方案哪个叙事好 | 已定这 1 个分镜好，只是要便宜地批量出 |

**判断（并列方案）**：本片工作流**补充了一个新档位**——"已确定用 Seedance 2.5 的运镜/表演，但不需要原生高分辨率"的场景（门店屏/抖音信息流/内部版本）。它不替代"2.0 Fast 粗剪"（那是试模型/试剧本阶段），也不替代"2.5 原生精修"（那是交付阶段）。我方流水线可排成：
```
2.0 Fast 试分镜（淘汰废方案）
  → 480P 2.5 + Flova超分（门店屏/抖音信息流量产，便宜）
    → 2.5 原生 1080P（客户交付/品牌主视觉）
```

### 6.4 可复用工作流与提示词（逐条标注来源）

**工作流步骤（[已查证] 关键帧 UI）**：
1. Flova 内用 Seedance 2.5 以 **480P** 生成目标镜头（提示词按正常写，分辨率选 480P）；
2. 生成完成后，在项目素材右上角点"视频超清"；
3. 弹窗选：分辨率=4K（或 2K/1080P 按用途选）→ 补帧模式=高质量补帧 → 帧率=30fps → 创建；
4. 等待超分完成，下载成片。

**注意点（[博主评论区已查证]）**：
- 480P 底版**不适合面部精细复刻**：要脸/五官细节，得用半身或面部特写做参考，且底版至少 1080P——超分救不回"原图就没有的细节"。
- 价格是否长期：博主自己也不确定（"至少一年吧"），**预算别按长期低价锁死**。
- 超分质量对标 Topaz/达芬奇（博主答应做对比视频），但**未实测对比前不预设等同专业超分软件**。

**提示词**：本片未逐字展示完整提示词（帧上仅见一段射箭武侠镜头描述，过小未抄录），[未经核实] 不编造；可复用的是**分辨率选择策略**而非提示词文本。

## 七、对珠宝项目的启示

1. **门店循环屏 + 抖音种草 = 这套工作流的主战场**：远观场景大胆用 480P+超分，成本压到 0.2 元/秒量级，批量出片不心疼。
2. **客户交付/蓝宝石微距 = 坚决不省**：超分只放大不造细节，宝石火彩、镶口金属反光必须原生高分辨率。
3. **4 项自检别在 480P 底版上做**：链条/五官/手部/吊坠居中的质检，应在 720P/1080P 原生档做，480P 超分后会"假装清晰"掩盖变形。
4. **与 Flova 平台调研互证**：本片是 flovaa_platform_research.md 中"促销 0.175 元/秒""4K 疑为超分 Skill"两条结论的**一手视频实证**——博主年费折算 0.17 元/秒与 818 促销价吻合；"4K"确实是超分功能产出而非原生。
