## 二、内容文稿

核心洞察（博主原话，已查证章节要点）：
- **直接拿原视频当参考，复杂镜头（环绕运镜/转身/挥拳）人物走位构图容易跑掉**；
- **把原视频先变成"干净的深度参考"，只留下运镜、动作和空间关系，效果反而更好**。

流程：导入原视频 → 提取深度视频 → 截取画面并设计效果 → 用视频模型生成。

## 三、叙事结构与情绪弧线

教程类短片，结构为：立反常识观点（"参考素材不是越完整越好"）→ 演示深度提取流程 → 对比效果。情绪钩子是"原来参考太满反而坏事"。

## 四、镜头语言拆解

方法核心不在镜头美学，而在**参考素材的处理方式**：把"画面内容"与"运动/空间关系"解耦——原视频提供运镜与走位骨架，新画面在骨架上重新生成。

## 五、可复用提示词 / 方法论

**运动/空间与画面解耦方法论（博主一方说法，[已查证]原话）**：
```
导入原视频 → 提取深度视频（只留运镜/动作/空间关系）→ 截帧设计 → 视频模型生成
```
- 价值：复杂运镜（环绕/转身/推近）时，避免直接喂原片导致人物走位/构图漂移。
- 与 #8 小朱朱白模、#7 LibTV 深度动作捕捉三方互证：**白模/深度 = 运动控制的正解**。

## 七、对珠宝项目的启示

1. **珠宝运镜解耦**：我方需要环绕项链、推近蓝宝石火彩等复杂运镜时，可先做"深度/白模运镜参考"再换画面，避免成品直接生成时画面漂移变形——与 #8 白模驱动、#1 姜颜抚琴手部特写互补。
2. **"参考不是越满越好"是反直觉但重要的教训**：喂太多原片信息反而锁死构图；干净的运动骨架 + 明确的产品图，出片更可控。
3. 反哺：无模特版 SOP 运镜章节、广告叙事分镜章节可吸收"深度参考解耦"作为复杂运镜的候选方案（并列：白模驱动 / 深度提取 / 首尾帧）。
