## 五、分镜衔接方法论（本视频核心交付物）

**小白分镜拆解框架（镜号/景别/内容）**：
1. 先定**场景图**（在哪），再定**人物多视图+角色卡**（是谁、长什么样）；
2. 然后才逐镜写分镜图：**环境 + 主体动作**两个要素写全；
3. 每镜标注**景别与机位**（特写/中景/全景/大远景），避免同景别硬切（博主评论区原话："一直同景别切的话，画面跳得难受"）。

**镜头间衔接三法**：
- **动作衔接**：上一镜尾帧动作 ↔ 下一镜首帧动作承接（评论区高赞补充："先设计动作承接点，画面连上了叙事才不中断"）；
- **文本表达衔接**：用一句旁白/台词缝合两个场景（演示："切到下一个场景了，让整座山缓缓落进眼里"）；
- **景别切分**：相邻镜头换景别（特写→中景→全景），画面自然有节奏。

**博主自己的进阶建议（评论区）**：拉片——"看电影电视剧时观察导演怎么切镜头、怎么做场景衔接，慢慢积累"。

## 六、可复用提示词与经验

- 分镜图提示词写法（从演示反推）：`<场景环境描述> + <主体在做什么动作> + <景别/机位> + <光线>`，如"藏式石墙前，女生背影驻足仰望雪山，全景，高原日光"。

- 大场景策略：不硬生成长镜头，**拆成多镜+剪辑拼接**。
- 心态策略：70 分上线，故事优先。

### 4. 音画配合逻辑（重点：分镜示例片段的音画节奏）
- **自证闭环**：博主教"文本表达衔接"，他自己就在用——3:50 处画面从"女生伏案写字"硬切到"藏式建筑前望雪山"，**切镜瞬间旁白响起："切到下一个场景了，让整座山缓缓落进眼里"**。旁白本身就是缝合两个场景的那根线：观众耳朵先被旁白告知"要换场景了"，眼睛再看到新画面，转场就不突兀。
- **节奏配合**：工作区录屏段口播密集（信息段）→ 一切到成片（雪山/面具）口播立刻让出频率、画面放慢（雪山缓落镜头）——**音画同呼吸：讲方法时密，展示成片时疏**。
- 情绪锚点：5:20 面具特写这种"大场景里的细节镜"出现时，是听觉留白+视觉冲击的组合。
- 起承转合：起（0:15 痛点画布，口播密）→ 承（1:03-3:14 方法讲解，口播密+字幕节点）→ 转（3:50/5:20 成片展示，口播疏+画面缓）→ 合（7:20 回到画布总览，口播收尾降压）。

### 5. 为什么这个音频适合这个视频
- **这是一条"教分镜"的视频，音频层自己就是教具**：博主没有空讲"文本衔接"，而是用一句"切到下一个场景了"的旁白当场演示。观众既听方法、又听方法生效的声音现场。

### 6. 可复用音频配方
- 配方：`快口播男声（讲解段密集）+ 成片展示段口播让出、环境氛围音垫底 + 场景切换点用一句旁白缝合（"切到下一个场景，让XX缓缓…"）+ 结尾降压句`。
- 旁白缝合句模板：`"切到下一个场景了，让<主体>缓缓<动作/进入画面>`——可作为借鉴句式试套我方珠宝片（复现效果需实测）："换一个场景，让蓝宝石的火彩缓缓落进眼里"。
