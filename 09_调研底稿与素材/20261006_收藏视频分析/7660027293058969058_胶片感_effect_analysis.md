## 五、可复用方法（流程 + 模型选型 + 提示词公式）

### 全流程 SOP（7 步）
```
参考图（关键词搜风格） → 人物30图（去脸→三视图+脸特写） → 场景（真实提取或文字生成，多角度连贯）
```

### 模型选型（博主一方说法，t591 画面已查证）
| 模型 | 核心驱动 | 适合场景 |

### 胶片感提示词公式（抽象词→物理词）
- 胶片感 → **低饱和 + 暖色偏色 + 暗部颗粒（降噪保留） + 边缘柔化（模糊边缘） + 高光柔和**
- 真人感（呼应梳子玩Ai）：人物瑕疵感、不完美、呼吸感、微表情——"最后一块拼图"
- 提示词模板：`摄影机参数（镜头焦段/光圈/快门） + 画面质感（胶片/颗粒/色偏） + 分镜（景别/运镜） + 人物设定 + 场景（年代/地点/时间）`
