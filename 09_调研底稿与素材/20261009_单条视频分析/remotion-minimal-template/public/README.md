# public/ · 静态资源（音频）

> AnchorVideo 采用 Remotion「渲染前生成音频」模式，下列音频需在渲染前生成后放入本目录：
>
> | 文件 | 是什么 | 怎么生成 |
> |---|---|---|
> | `voiceover.wav` | 配音 | 用 `text_to_audio_plus`（体系内，免费）/ Edge TTS / ElevenLabs 按文案生成 |
> | `bgm.wav` | 背景音乐 | 用 `text_to_audio_plus` 生成纯音乐，或取免版税音乐 |
>
> 生成方法与配音文案规范见 video-studio《音频选择与生成SOP》。本目录不入库实际音频（版权 / 体积）。
