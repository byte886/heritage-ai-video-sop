## 一、LibTV 深挖

### 1.1 它是什么（归属 / 生态）

- **出品方：LiblibAI（哩布哩布AI）**，2026 年 3 月 18 日正式上线，官网 **https://www.liblib.tv/**。【已查证：CSDN 实操文 + AIHub 工具导航页，双方口径一致】
- **不是即梦/剪映（字节）生态产品**，而是**第三方"模型聚合 + 工作流"平台**：自己不产底层模型，底层接入可灵 3.0/O3、Seedance（即梦系）、MiniMax H3、Wan 2.6、Vidu、Pixverse 等 20+ 视频模型，图像侧接入 Seedream 5.0、Midjourney V7 等。【已查证：AIHub 导航页功能清单；liblib.art/video-effect 页面模型墙】
- **定位**：一站式视频创作工作台，覆盖"剧本→分镜→图片→视频→粗剪"全流程；核心设计是**无限画布 + 节点式工作流**。
- **"Creator + Agent 双入口"**：①人在画布上手动操作（Creator/GUI）；②AI Agent 通过 Skill/API 调用同一套画布能力（Agent）。两个入口操作的是同一块画布、同一套节点。【已查证：CSDN《LibTV Agent技术解析》架构图】

### 1.2 完整操作流程（Creator 模式，按钮级）

> 综合抖音多条实操录屏、腾讯新闻 2026-03-23 文、CSDN 实操文交叉还原。

1. **进画布**：浏览器打开 `liblib.tv` → 注册/登录 LiblibAI 账号 → 首页点 **「开始创作」** → 进入无限画布（首次弹新手指南）。
2. **建节点**：在画布空白处**双击** → 选节点类型。共 5 种：**文本 / 图片 / 视频 / 音频 / 脚本**。
3. **写/拆剧本**：
   - 新建 **「脚本节点」** → 粘贴已有剧本，或只输入一句话想法 → 点 **「生成」**。
   - 自动拆成多镜头分镜脚本，每个镜头带：时长、画面描述、景别、对话；**双击内容可直接改**。
   - 脚本生成有 **3 种模式**：①剧本生成分镜脚本；②视频参考生成分镜脚本；③角色生成分镜脚本。【已查证：腾讯新闻 2026-03-23】
4. **锁资产（可选但强烈建议）**：图片节点上传产品/角色图 → 选中图片 → 上方工具栏选 **「九宫格 → 角色三视图生成」**，锁定形象一致性。
5. **批量生成分镜图**：回到脚本节点 → 点脚本上方 **「生成分镜」** 按钮 → 左下角选生图模型、选比例（如 9:16）→ 批量出图；**单张不满意可单独重生成**。
   - 隐藏快捷键：在图像生成器里输入 **`/`**（Slash）调出：多机位九宫格、25 宫格连贯分镜、剧情推演四宫格、角色三视图、画面推演。【已查证：AIHub 导航页 + 抖音录屏】
6. **批量生视频**：把分镜图/参考图**连线**到「视频节点」（拖节点边缘的连接点拉一根线过去）→ 视频节点里**选模型**（Seedance 2.0 / 可灵 3.0 等）→ 提示词里用 **`@`** 引用素材（如 `@图片1 作为首帧，参考 @视频1 的运镜`）→ 点生成。
7. **粗剪/导出**：视频工具集支持片段裁取、2/4/6 倍放大、帧率提升（30/60/90fps）；**最终合成官方仍建议导出后进剪映**（内置剪辑"持续完善中"）。【已查证：AIHub 导航页"如何使用"第 5 步】

### 1.3 Agent 模式自动化能力边界

**A. 网页内 Agent 面板（低代码，无需写代码）**
- 操作：打开 LibTV 无限画布 → 找到 **Agent 面板** → 选平台自带 Skill（如"高奢感 TVC""电影制作全流程导演""中式审美"）→ 上传产品实拍图作参考 → 用一句话输出成片需求 → Agent 自动走：出脚本 → 裁剪 → 统一光影 → 配乐，**几十分钟出粗片**。
- 不满意不切软件：直接大白话描述修改（如"前三组镜头放慢运镜、提亮膏体质感"），Agent 实时调整故事板节点。【已查证：抖音录屏 2026-07-14 / 2026-08-23】

**B. 外部 Agent 调 Skill（全自动，需一点技术）**
- 开源仓库：`github.com/libtv-labs/libtv-skills`（MIT，Python）。
- 安装（以 OpenClaw/Claude Code 为例）：
  ```
  npx skills add libtv-labs/libtv-skills
  export LIBTV_ACCESS_KEY=your-access-key
  ```
  然后自然语言下指令（如"做一个 30 秒产品宣传片，赛博朋克风格"），Agent 自动完成建会话、上传素材、剧本/分镜/镜头生成、结果下载。【已查证：CSDN 文附 GitHub README 截图】
- Skill 分三层：原子 Skill（单操作）/ 组合 Skill（剧本→成片串起来）/ 领域 Skill（"西部片""MV""转爆款短视频"）；2026 年 6 月已上线 100+ Skill。

**自动化边界（哪些全自动 / 哪些要你点）**
| 环节 | 是否全自动 |
|---|---|
| 剧本拆解、分镜脚本生成 | ✅ Agent 自动 |
| 批量分镜图、批量视频片段生成 | ✅ 自动（单镜头不满意需你指定重抽哪条） |
| 统一光影、配乐、粗裁 | ✅ Agent 自动 |
| 注册登录、上传产品参考图、充积分 | ❌ 人工 |
| 结果检查、不满意反馈、最终导出 | ❌ 人工把关 |
| 批量生产多条 | ✅ 支持：工作流可"打组"存模板，下次换输入一键复跑；Agent 一次指令出多镜头 |

- 时长上限：系统支持 5 分钟以上成片，官方建议**测试阶段优先 ≤2 分钟**更稳。【第三方导航页口径】

### 1.4 移动端

- **纯 Web 应用**，浏览器（Chrome/Edge/Safari）直接用，无需安装软件。【已查证：CSDN 实操文 4.1 节】
- **未发现独立 App / 小程序**：搜索未见 App Store、微信小程序入口。【未能核实——结论暂按"无独立端"，上线前建议在手机浏览器实测一次画布可用性】

### 1.5 与「即梦智能画布」的差异

| 维度 | LibTV 无限画布 | 即梦智能画布（Ch09） |
|---|---|---|
| 本质 | **多镜头工作流画布**：文本/图片/视频/音频/脚本 5 类节点连线编排 | **图片后期精修台**：以单张图为中心做扩图/超清/抠图/改文字/局部重绘/消除/生成视频 |
| 中枢 | 脚本节点（剧本→分镜→批量出图出片） | 对话输入框（"添加到对话"二次生成） |
| 视图 | 故事板视图 ↔ 节点工作流视图切换 | 单项目画布，无节点连线 |
| 模型 | 20+ 模型聚合（可灵/Seedance/MiniMax…） | 仅即梦自有模型（Seedream/Seedance） |
| 自动化 | 开放 Agent Skill，外部 Agent 可全流程驱动 | 内置 Agent 模式，但不开放外部 API/Skill |
| 适合 | 多镜头、批量、要跨模型的 TVC/短剧 | 单图精修、单段视频生成 |

> 一句话：**即梦画布是"一张图的精修台"，LibTV 是"一条片子的流水线"**。珠宝 SOP 里两者可互补：即梦精修产品图 → LibTV 或即梦图生视频 → 剪映合成。

### 1.6 价格（积分会员制，照抄来源）

- LiblibAI 官方邀请奖励页：基础版 VIP 连续包月 **39 元/月**（年包 399 元）；专业版连续包月 **66 元/月**（年包 639 元）。【已查证：liblib.art/membershipInvitationBonus】
- 视频创作会员分标准版/高级版/至尊版，**569 元 – 8499 元/年**；高档年包见 viphome（¥22999/年档：50500 积分/月，自称 1 积分≈0.017 元）。【经搜索补充：36kr 引官网 + liblib.art/viphome】
- 第三方博主实测：45 元/月会员送 1500 积分，3 条视频抽卡用完（其中一条 30 多秒耗 21.9 元）。【第三方说法：抖音 2026-08-05】

### 1.7 使用要点 & 避坑点

- **@ 引用必须写清素材角色**（"@图片1 作为首帧""@视频1 参考运镜"），不写清模型会乱配——新手最常踩。
- **真人素材合规**：LibTV 接入的 Seedance 2.0 系列在即梦官方口径"暂不支持真人人脸相关视频"（写实人像驱动、对口型），LibTV 作为同一模型的分销端限制一致。
- **中间商模式风险**：LibTV 自己不产模型，上游（即梦）调价会传导；36kr 报道即梦 2026 年 4 月三连调、视频成本翻近 6 倍后，LibTV 才成为从业者"平替"。
- **积分大头在视频**：生图便宜，抽视频吞积分；正式投放前先用便宜档位抽卡定分镜。

## 二、Seedance 版本对比（珠宝视频场景）

### 2.1 版本对比表

> 界面基准：即梦 App 2026-07-31 实测截图（极目新闻）+ 即梦教程站 2026-04-14 截图 + 字节 Seed 官方博客 2026-07-31。
> 模型列表随时间演进：4 月教程截图为"2.0 Fast VIP / 2.0 VIP / 2.0 Fast / 2.0"四档；7 月实测截图为"**2.5 / 2.0 Mini 体验版 / 2.0 Mini / 2.0 Fast VIP / 2.0 VIP / 1.5 Pro 限免 / 1.0 Fast**"。下表只对比 SOP 相关三档。

| 维度 | Seedance 2.0 Fast | Seedance 2.0（标准/VIP） | Seedance 2.5 |
|---|---|---|---|
| **定位** | 高性价比快速版，极速推理 | 全模态旗舰 | 长叙事新一代，一镜成片 |
| **单次时长** | 3–15s（教程站口径 3–15s 档位） | 3–15s | **5–30s 单次直出**，支持多轮延长（官方称可连贯数分钟）【官方原文：Seed 博客】 |
| **分辨率** | 480p / 720p（第三方 API 文档口径，Fast 不出 1080p/4K） | 480p 起，标准档可更高 | 实测界面 720P；官方宣传 **4K 纯净画质** |
| **输入参考上限** | 图≤9 + 视频≤3（总≤15s）+ 音频≤3（≤15s） | 同左（全能参考） | **图≤30 + 视频≤10 + 音频≤10（共 50 个）**【官方原文：Seed 博客】 |
| **首尾帧** | 支持（教程站：各视频模型普遍支持） | 支持 | 支持，另增**时间戳精准编辑 / 局部编辑 / 绿幕编辑 / 白模参考** |
| **智能多帧** | 教程站标注"仅 Seedance 2.0 支持"【以客户端为准】 | 支持（多关键帧插值，0–8s/帧） | 未单独标注【未能核实】 |
| **@引用/全能参考** | 支持（Fast VIP 界面可选"全能参考"） | 支持 | 支持，新增 **R2V 参考视频控制动作/运镜** |
| **音画同步** | 原生音效+配乐+音乐卡点 | 同左（DB-DiT 双分支架构，音画同出） | 同架构，**专门优化"油腻感"、减少不受控字幕/BGM** |
| **产品一致性** | 多镜头角色/光影/风格一致 | 同左 | 30s 内主体/服装/光线/场景一致，多主体群像也能保形 |
| **积分消耗（720P，非会员实测）** | 教程截图：15s/16:9 ≈ **165 积分**（Fast VIP） | 极目实测：5s=70 / 10s=140 / 15s=210 积分 | 极目实测：5s=130 / 10s=260 / 15s=390 / **30s=780** 积分 |
| **会员门槛** | 有 VIP 档（会员专属通道）；非 VIP 也有 Fast 入口 | VIP 档=会员专属通道 | 界面标注"会员积分消耗"，首发 720p 低至 6.2 折；知识库口径"高级会员"【以客户端皇冠标识为准，国内非会员能否直开 2.5 未逐人核实】 |
| **真人人脸** | **暂不支持**（写实人像驱动/对口型） | 同左 | 官方未放开此限制【避坑】 |

**即梦会员价（照抄来源）**：基础会员连续包月 **41 元/月 = 725 积分**；标准会员 **239 元/月 = 2210 积分**（极目新闻 + 腾讯新闻）。按此折算：2.5 一条 30s/720P = 780 积分 ≈ 占标准会员月额度 1/3、约 84 元/条（腾讯新闻折算口径）。

### 2.2 珠宝场景选型建议

**场景 ①：无模特版产品旋转微距（约 10s，珠宝原片同款）**
→ **选 Seedance 2.0 Fast**。
- 做法：图生视频，首帧=珠宝实拍图；提示词写运镜（"镜头缓慢环绕戒指 / 微距推进主石 / 柔光打在钻石火彩上"）+ 光线 + 背景。
- 理由：静物旋转不需要 30s 长叙事；10s ≈ 140 积分（2.0 VIP 口径，Fast 更低），抽卡量产成本最低；Fast 画质对静物产品足够。
- **不要上 2.5**：积分贵近 2 倍，10s 场景用不满它的长叙事能力。

**场景 ②：模特佩戴版**
→ **当前有合规硬墙**：Seedance 2.0 系列"暂不支持真人人脸相关视频"，AI 写实人脸模特 + 对口型这条路在即梦端被堵。
- 可行替代：① 非写实路线（国风插画 / 3D 皮克斯 / 剪影背影，不露正脸）；② 真人模特实拍 + AI 只做背景/运镜后期；③ 持续等合规放开后再做写实佩戴版。

**场景 ③：10–15s 详情展示（多卖点镜头串联）**
→ **日常量产用 Seedance 2.0 标准版（全能参考）**：多张珠宝角度图 `@` 引用，一段内多镜头叙事（正面→侧面→主石特写→佩戴氛围），15s=210 积分。
→ **正式投放的 30s 一镜到底大片再用 Seedance 2.5**：不拼接、主体 30s 不走脸，但 780 积分/条，只适合定稿片，不适合反复抽卡。

### 2.3 使用要点 & 避坑点

- **模式三选一互斥**：首尾帧 / 智能多帧 / 全能参考是三种模式，别在同一次生成里混着用（API 文档口径）。
- **分辨率跳涨积分**：480P 抽卡定调 → 720P 出片 → 别直接 1080p/4K 抽卡。头条博主实测 30s 视频：480P=270 积分 vs 1080P=1920 积分（7 倍差价）。
- **提示词公式**（即梦教程第十章，已读不展开）：`[主体], [运镜]+[速度/情绪], [光线], [风格], [技术参数]`；运镜面板与提示词二选一。
- **时长别硬拉**：动作多、转场多的镜头宁可拆成多段 5–10s 生成再剪映拼接，比硬拉一条 15s 稳。
- **数字人/口播别指望 Seedance**：真人人脸相关成片暂不支持。
