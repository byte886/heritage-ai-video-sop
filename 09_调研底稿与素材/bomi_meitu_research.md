## 二、美图设计室 · 服饰穿戴功能（项链平铺图→模特穿戴图）

来源：https://www.designkit.cn/article/fushichuandai-yijianchengtu
文章标题：《服饰穿戴功能怎么用？一条项链从平铺到模特展示图》
发布时间：2026-06-09
查证状态：【已查证：页面原文】

### 2.1 功能定位
"服饰穿戴"功能在美图设计室官网首页有入口，专门针对项链、耳环、发饰等需要上身展示的商品。不是把图抠出来贴人身上，而是**根据项链的链长、吊坠大小、材质反光，重新计算佩戴后的位置和光影**。

### 2.2 完整操作步骤（编号列表，按文章原文）

1. **拍摄/准备项链平铺图（上传前）**
   - 链条自然展开：不要堆成一团，也不要拉得太直；理想弧度是模拟佩戴时自然垂坠的拉长 U 形，吊坠在正中间朝上。
   - 光线均匀打在吊坠上，金属反光部分别过曝；手机拍摄时长按屏幕锁定对焦，稍微拉低曝光补偿，让金属纹理清晰可见。
   - 拍完放大检查：链条每一节是否分明，吊坠边缘有没有模糊。

2. **进入服饰穿戴功能，上传图片**
   - 从官网首页进入"服饰穿戴"功能。
   - 页面上方区域写着"上传服装图片"，点击该区域，从本地选择项链平铺图。
   - 上传成功后页面显示图片预览。

3. **定制专属模特（页面中间偏右模特设定区域，依次选择）**
   - 性别：选"女"（选项栏有"男"/"女"）。
   - 年龄段：选"青年"。
   - 人种：选"中国人"（文章原文强调：亚洲女性和欧美女性颈部比例不同——锁骨位置、肩颈线条、脖子长度都有差异，选"中国人"后AI按亚洲女性骨骼结构放置项链）。
   - 体型：选"标准"（文章提示：短锁骨链约40cm，标准体型效果刚好）。
   - 外貌细节（可选，最下方输入框）：占位提示文字原文为"例如：小麦色皮肤、齐刘海、眼角有泪痣"；标准电商主图可留空；做耳环时可写"披发"控制头发遮挡。

4. **点击"生成基准模特"按钮**
   - 文章明确提醒：**这个按钮是先生成模特形象，还没有把项链放上去**。

5. **点击"生成推荐场景"按钮，等待出结果**
   - 处理时间约十几秒，页面有加载提示。
   - 出现"选择场景"功能，场景示例原文："生吃咖啡露台""简约居家客厅"等。
   - 选好场景后点击"生成场景图"。
   - 从文章截图可见场景选择面板还包含：模特设定（特写/正常）、景别（半身/3/4身）等选项。

6. **查看生成结果**
   - 生成完成后下方出现结果图片，原文截图为一组 5 张：1 张平铺原图 + 4 张模特佩戴图（文件名示例"锤头吊坠双层项链 2026-04-25 09:42"）。
   - 项链已"戴"在选定模特（女、青年、中国人、标准体型）颈部。

7. **不满意则重新生成**
   - 保持所有设定不变，直接再次点击"AI生成"，系统换一批结果。
   - 每次约十几秒，不需要重新上传项链图或重选模特。

8. **结果页底部操作选项**
   - "下载"：保存当前图片到本地。
   - "重新生成"：吊坠角度歪、链条走向有问题时点这个，重新输出一批。
   - "编辑模特"：佩戴位置太高（吊坠快到喉咙）或太低（掉到领口以下）时点这个，返回调整体型设定后重新生成。

### 2.3 同一张生成结果的三种用法
| 产出图 | 用法 |
|---|---|
| 项链白底图 | 生成结果背景干净时直接用；背景不准则用美图设计室"智能抠图"把项链和模特一起抠出，换白色背景。淘宝要求白底、京东要求白底或浅灰底。 |
| 项链模特展示图 | 佩戴图本身直接用，放详情页中部，展示吊坠在锁骨的位置、链长高度、金属光泽反射。 |
| 项链电商主图 | 佩戴图直接作主图第 2–3 张；若平台要求首张白底，则白底图放第一张，佩戴图放第二/三张。 |

### 2.4 参数 / 预设（原文引用）
- 模特四要素：性别 / 年龄段 / 人种 / 体型（均为下拉选项）。
- 外貌细节：自由文本输入框，占位符"例如：小麦色皮肤、齐刘海、眼角有泪痣"。
- 场景预设：原文举例"生吃咖啡露台""简约居家客厅"。
- 景别选项（截图可见）：半身 / 3/4身；模特特写：特写 / 正常。
- 图片比例（截图可见，左侧面板）：1:4、1:1、9:16 三个比例选项（从截图"□ 1:4 □ 1:1 □ 9:16"读得）。
- 单次生成张数：截图显示一次出 4 张场景图（+1 张原图缩略）。

### 2.5 避坑点（文章原文提到的失败案例与注意事项）

1. **链条扭成 8 字形或吊坠歪到一边** → AI花更多时间判断结构，佩戴位置可能偏离预期。
2. **金属反光过曝** → 吊坠刻字、纹路、光泽层次丢失，生成后吊坠材质感差。
3. **吊坠角度歪斜**（不垂直地面）→ 点"重新生成"再跑一次。
4. **链条交叉 / 断裂**（两条链节交叠、某段凭空消失）→ 点"重新生成"换一批，或生成后用"消除笔"工具修复。
5. **原图光线不足** → 先用智能抠图提取项链，再用基础编辑"调亮"+"对比度"提升清晰度后再上传；但若吊坠细节完全模糊或链条严重过曝，调亮无法恢复，建议重拍。
6. **金银两版同图上传** → 不要在一张图里同时放金色和银色两条项链，AI无法判断主体；应分两次上传，保持相同模特设定，两组图佩戴位置/光影/焦距才一致。
7. **背景非纯白** → 服饰穿戴功能界面上**没有单独的纯白背景选项**；需走"生成佩戴图→下载→智能抠图去背景→加纯白背景图层→导出"流程。
8. **模特人种选择** → 做国内年轻女性市场时不要用欧美脸，否则用户感觉"戴在我脖子上不是这样"。

## 三、美图设计室 · AI设计 Agent（一键同款-模特穿戴）

来源：https://www.designkit.cn/article/zbxlcyzst20251014
文章标题：《用美图设计室AI设计Agent，零基础店主也能快速生成高级感电商大片》
发布时间：2026-06-09
查证状态：【已查证：页面原文】

### 3.1 功能定位
"AI设计Agent"中的**"一键同款-模特穿戴"**入口：上传项链平铺图，AI自动生成真人佩戴效果，背景光影一步到位。系统会**自动适配一套提示词**，用户只需根据商品特点稍微删减或补充。针对服饰和配饰类商品（项链、耳环、戒指等珠宝首饰）。

### 3.2 完整操作步骤（5步，按文章原文）

1. **进入首页，找到"一键同款"里的"模特穿戴"**
   - 打开美图设计室官网或 App，首页 → "一键同款" → "模特穿戴" → 点击"做同款"。
   - 系统自动适配一套提示词，不需要从零写。

2. **上传产品图片**
   - 点击上传区域，选择项链平铺图或细节图。
   - AI自动识别项链主体、快速抠图，并根据模特光线环境自动调整项链光影和角度，使其与模特脖子光线方向一致。

3. **一键生成设计效果**
   - 点击"开始生成"（界面右下角蓝色发送按钮）。
   - 约 15 秒出图。
   - 不满意点"换一批"重新生成不同姿势或背景。
   - 从截图可见左侧对话区系统预置提示词为："一个模特戴着这个项链，模特不露脸"；AI自动回复："我来帮你生成模特佩戴这条项链的效果，模特会保持不露脸的状态，让我好好构思一下这个展示效果。"

4. **导出高清电商图片**
   - 点击右上角"导出"/"下载"。
   - 比例选择：1:1（电商主图）或 3:4（小红书）。
   - 分辨率选高清。
   - 导出格式选项（截图可见下拉菜单）：PNG、JPG、SVG。
   - 几秒后下载无水印图片。

### 3.3 参数 / 预设（原文引用 + 截图可见）
- 入口路径：首页 → 一键同款 → 模特穿戴 → 做同款。
- 系统自动提示词示例："一个模特戴着这个项链，模特不露脸"（可自行删减补充）。
- 导出比例：1:1（电商主图）/ 3:4（小红书）。
- 导出格式：PNG / JPG / SVG。
- 生成时长：约 15 秒。
- 界面右上角显示积分数值（截图中可见"10""86"等数字），说明美图设计室采用**积分制**。

### 3.4 付费模式（文章FAQ原文）
- 免费用户可**体验**模特穿戴功能，生成**带水印预览图**。
- 下载无水印高清图、使用更多高级模板和商用素材需开通会员。
- 文章原文："会员权益可以无限次生成高质量商品图，成本远低于请设计师或模特拍摄。"
- 版权：平台模板和素材有版权授权，生成图可用于淘宝、拼多多主图详情页及小红书、抖音宣传；用户上传的项链图须为自己拍摄，不侵犯他人版权。

### 3.5 适用场景
- 淘宝店主、微商、小红书博主。
- 服饰配饰类：项链、耳环、戒指等珠宝首饰。
- 快速产出多种风格展示图，适合商品图更新和上新。

### 3.6 避坑点
1. **上传图背景要干净、形状完整**：文章建议放在白纸或纯色背景上拍摄；否则AI识别不准，项链"浮"在脖子上，不贴合皮肤。
2. **不要期望一次到位**：不满意就点"换一批"，文章未说固定重试次数。
3. **免费版有水印**：商用必须开会员下载无水印图。
4. **文章为营销软文性质**：文中"转化率至少提升50%""一分钟搞定"等表述为宣传口径，SOP中不应直接引用为客观数据。
