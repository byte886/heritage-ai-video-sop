## 二、三条方法链（可直接复用）

### 链1：活人感（模特要"活"）
```
生图（seedream 5.0 pro，用户截图经验）→ 图生视频（即梦 Seedance 2.5）→ 活人感提示词
```
**活人感 = 不完美的生命细节**（物理词清单）：
微表情细腻｜真实呼吸感｜头部自然微动｜眼珠自然转动｜碎发丝散落｜胎毛刘海｜皮肤肌理｜瞳孔环境倒影｜伪素颜淡妆｜柔和漫射光
负面清单：卡通/塑料皮肤/过度磨皮/浓妆/表情僵硬/AI崩坏/面部闪烁
⚠️ 合规：Seedance 2.0 系列不支持真人人脸正脸视频；锁骨+侧脸不受影响（项目 SOP 已有约束）

### 链2：胶片电影感（故事感片子的画面基础）
```
参考图 → 人物30图（去脸→三视图+特写） → 场景（真实提取或文字，多角度连贯）
→ 风景图（可灵，高性价比） → 视频提示词（三视图+场景+参数+质感） → 模型 → 后期
```
- **模型选型**：Seedance（即梦）= 提示词核心，统一质感/复杂动作；Keling（可灵）= 参考图核心，分镜/高性价比
- **后期三件套**：降噪（暗部颗粒控制）+ 调色（低饱和偏暖）+ 模糊边缘（柔化AI边缘）→ 减少AI感
- 胶片感物理词：低饱和、暖色偏、暗部颗粒、边缘柔化、高光柔和
- 视角控制（Shotlab）：鱼眼/倾斜/正面俯拍/正面仰拍/全景俯拍/左右旋转/垂直角度/广角镜头

### 链3：白模驱动工作流（运动控制）
```
白模视频（GPT可生成）→ 截首帧 → 图生视频直接生成 → 少量积分
```
- 目的：**运动与画面解耦**——直接生成成品会被原角色/场景污染，白模只提供运动轨迹
- 无参考图时：一句提示词直接生成
- 价值：珠宝运镜（旋转/环绕/推近）可控、低成本试片

```

+ 光线（柔和漫射/黄金时刻/逆光） + 质感（皮肤肌理/胶片颗粒/色偏） + 负面清单
```

## 四、对珠宝项目的落地映射

| 珠宝场景 | 用哪条链 | 具体做法 |
|---|---|---|
| 模特佩戴图（项链嵌蓝宝石改款） | 链1 活人感 | seedream5.0pro 生成佩戴图 → SD2.5 图生视频（锁骨+侧脸方案） |
| 故事感珠宝片（旅拍/剧情） | 链2 胶片感 | 人物30图改造为佩戴多角度一致性 + 可灵风景图 + 后期三件套 |
| 产品展示运镜（旋转/环绕） | 链3 白模 | 白模运镜视频 → 截首帧 → 图生视频，避免画面漂移 |
| 低成本试片 | 链3 | 一句提示词直接生成白底展示片 |

**三层叠加公式**：白模管运动轨迹 + 提示词管画面质感（活人感/胶片感）+ 后期管减少AI感
