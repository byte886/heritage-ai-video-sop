## 二、迭代规则（硬约束）

1. **顺序固定**：G1 → G2 → G3 → G4 → G5；视频类检查（G4/G5）**永远最后执行**——生成视频消耗 Token，必须在图片与方案全部达标后才允许消耗。
2. **任一不满足不迭代**：任何一道门禁有未通过项，立即回到对应阶段修正，**不进入下一道门禁**；修正后重跑该阶段全部检查项（不是只查改的那一项）。
3. **评估报告＝终产物**：只有 G1–G5 全部通过后，才产出**完整评估报告**（记录每轮检查结果、修正记录、终检结论），报告是本次迭代的最终交付物之一。
4. **多次检查**：同一次任务可多轮检查；每轮检查结果写入评估报告草稿，最终版仅在全部通过后定稿。
5. **多智能体复查制**：重大交付（定稿 SOP、正式出片）由独立评估 Agent 复查，不复用主 Agent 自查结论。
6. **触发时机**：T1 新 SOP 定稿 / T2 大任务完成 / T3 季度巡检 / T4 跨文档矛盾出现。

## 三、G2 执行计划检查（出图/出视频前）

- [ ] **G2-01 产物参数完整**：模型（如 Seedance 2.0 Fast）、时长、比例、输入图/核心资产 CDN 均已锁定
- [ ] **G2-02 分镜完整**：镜头序列/转场/收尾动作可逐镜执行，无"自由发挥"空档
- [ ] **G2-03 成本预算**：积分预估 + 重抽余量（10s≈140积分基准），预算内可完成
- [ ] **G2-04 与 SOP 一致**：术语口径（蓝宝石用"高光/台面反光"，不用"火彩/彩虹色散"）、无真人正脸、无编造事实/价格
- [ ] **G2-05 提示词合规**：抽象词已翻译为物理词；运镜面板与提示词**二选一**；无占位符/平台名/工具字段
- [ ] **G2-06 音频方案**（含配音/BGM 时）：声线人设四维匹配（感知年龄/性别/能量/语调）+ BPM 选型 + 高潮对齐画面转折
- [ ] **G2-07 交付路径明确**：present_files 通道 / 微信直发客户 / 剪映分享，已确定
- [ ] **G2-08 来源标注**：计划中引用的事实/数据带四档标注（已查证/经搜索补充/博主一方说法/未经核实）

## 四、G3 图片检查（出图后、交付前）

- [ ] **G3-01 产品微距 5 要素**：高光闪烁/金属质感/镶爪细节/背景干净/台面倒影
- [ ] **G3-02 人体 4 项**（模特版）：链条无变形、五官自然、手部自然、吊坠居中
- [ ] **G3-03 保真**：与选定方案图/核心资产一致，未凭空改款（95%+ 保真线）
- [ ] **G3-04 无文字问题**：无乱码/错误刻字（如 LOVE 刻字逐字核验）、无多余水印
- [ ] **G3-05 比例画幅**：9:16/16:9/1:1 按交付场景正确
- [ ] **G3-06 分辨率**：目标 ≥2048（工具上限内执行）
- [ ] **G3-07 交付合规**：逐张 present_files（生成一张交付一张，不合并）

## 五、G4 视频检查（生成后、封装前）

- [ ] **G4-01 抽帧质检**：抽首/中/尾帧（如 f001/f005/f013），产品一致性（与输入图同款同色）
- [ ] **G4-02 镜头结构**：蓄势→揭示→收尾完整，无穿模/悬浮/金属变形
- [ ] **G4-03 运动自然**：旋转匀速不抖动，宝石高光持续出现
- [ ] **G4-04 无文字水印**：无台标/水印/乱码字幕
- [ ] **G4-05 时长比例**：与参数一致（如 13s/16:9）
- [ ] **G4-06 人脸合规**：无真人人脸正脸（Seedance 2.0 限制；锁骨+侧脸可）
- [ ] **G4-07 抽卡筛选**：多条候选时逐条暂停检查后再定（抽卡不筛选＝返工源头）

## 六、G5 音频+成片终检（交付前）

- [ ] **G5-01 声线人设**：感知年龄/性别/能量/语调与受众预期匹配（珠宝＝克制高级，不甜腻不粗粝）
- [ ] **G5-02 语调情绪**：旁白情绪符合产品调性；诗性/克制/留白优先
- [ ] **G5-03 节奏对齐**：音乐高潮对齐画面转折/产品揭示点
- [ ] **G5-04 拟音自然**：拟音标签（`<丝绒轻抚><金属轻响>` 类）真实不突兀
- [ ] **G5-05 字幕调性**：字体/字号/位置符合片风，不遮挡产品（珠宝片默认关字幕）
- [ ] **G5-06 BGM 调性**：BPM 情绪映射正确（珠宝静物片 70-100 BPM 低频弦乐+钢琴）；无违和曲风
- [ ] **G5-07 成片可播放**：无水印（会员状态确认）、文件完整
- [ ] **G5-08 可交付**：微信可发送（格式/大小）、或剪映分享链接可打开
- [ ] **G5-09 自播一遍**：交付前完整播放一次，确认音画同步、无跳帧

## 七、评估报告模板（全部门禁通过后产出）

```markdown
# 质量评估报告 · <任务名> <YYYYMMDD>
- 状态：全部通过（G1✓ G2✓ G3✓ G4✓ G5✓）
- 任务：<目标/交付物>
- G1 SOP 检查：<清单版本> → 发现 X 项（高/中/低）→ 修正记录
- G2 执行计划：参数锁定/分镜/成本/音频方案 摘要
- G3 图片检查：5 要素/人体 4 项/保真/文字 结果
- G4 视频检查：抽帧结论/镜头结构/运动/水印 结果
- G5 音频终检：A1-A6 + 成片 结果
- 迭代记录：第 N 轮修正了什么 → 复检结论
- 遗留风险：未核实项/待验证项（引用 ISSUES 编号）
```
