## 一、核心认知：先有鸡后有蛋

**学习分镜必须先学导演思维**。分镜只是"分法"，没有思维就是照猫画虎；看完一段分镜能数出镜头，但不知道为什么这样分，等于没学会。

**导演思维 = 导演动机 + 导演工具**
- **导演动机**：这个场景要表达什么、该如何表达（目的层）
- **导演工具**：景别、视角、运镜、焦段、构图、声音等（手段层，前提是熟练）

**服务关系**：景别、视角等所有分镜元素都是**服务于导演思维的可视化工具**。动机变 → 工具变 → 分镜逻辑变。

## 二、三个案例的方法论提炼（可直接复用规则）

### 案例1：《海蒂和爷爷》进村找爷爷（外部观察 vs 人物刻画）

**场景A（8镜头全外部观察视角）**：大全景→小全景→近景→小全景→大全景→小景圈，全程外部视角，区别只在景别缩放。
→ **导演动机**：平铺直叙介绍环境，让观众看到外部环境与每个人的情绪，但**不激化情绪、不进入任何人立场**。

**场景B（海蒂个人刻画）**：进入海蒂视野（主观镜头）→ 海蒂反应（做决定）→ 位置关系 → 脱衣服动态特写（动态性最强=情绪最强烈处）→ 射出去（动态跟随）→ 海蒂视野收尾。
→ **导演动机**：在故事进行中刻画人物形象。核心技术 = **主观镜头 + 长焦特写动态刻画**；动静结合、景别与焦段组合、第三人称+第一人称综合应用。

### 案例2：镇上换粮食（笔墨分配）

- 景别**死死锁在人物近景**：因为外人敌意，海蒂和爷爷警觉（景别=情绪状态）
- 新人物（工具人）：只在全景**一笔带过**
- 牧师：**先有声音后给反应**，中近景进入，突出重要性

→ **规则：笔墨分配**。开拍前先分清"谁是主角、谁是工具人、笔墨深浅给谁"——这是老手基础，却是新手常栽的坑。

### 案例3：爷爷焦虑状态（情绪表达三招）

正面跟镜头 + 反面跟镜头 → 地景静 → 情绪特写 → 大环境：
1. **慢速跟镜头 = 无力感**（跟镜速度就是情绪速度，急=紧张、慢=无力）
2. **环境压制**：大环境压小人物，强化渺小无助（中国影视摄影师学会确认：人物占画面极小面积显渺小）
3. **长镜头**：情绪极度浓烈且无法消化时用长镜头记录（巴赞景深长镜头理论、《大象席地而坐》同源）

## 三、分镜设计五步法（从思维到镜头）

```
①定导演动机（这段要观众记住/感受什么）→ ②定视角策略（外部观察/主观/混合）
→ ③定景别节奏（全景铺环境/近景锁情绪/特写炸细节）→ ④分配笔墨（谁是主角谁是工具）
→ ⑤选运镜与时长（跟镜速度=情绪速度；浓烈情绪用长镜头）
```

**运镜情绪语法**（Robert Bruton 补充）：推镜=压力/觉悟，拉镜=孤立/后果；"摄影机在人物情绪变化时才动"（不做无目的运动，北电摄影系王博学）。

## 四、珠宝 AI 视频映射（落地到你的业务）

| 业务场景 | 导演动机（先定） | 工具落点（分镜） |
|---|---|---|
| 产品展示片（无模特） | 产品保真+质感证明 | 全景环境→微距长焦巡航（链节/宝石切面/刻字）→稳定 packshot；笔墨全给产品 |
| 模特佩戴片（锁骨侧脸） | 佩戴效果+氛围种草 | 中近景锁佩戴区域（=案例2"锁近景"），吊坠居中=唯一主角；手部/衣领是工具人不抢戏 |
| 故事感片（未来） | 人物情绪+叙事 | 主观镜头刻画体验者视角；跟镜速度=心动/郑重感；浓烈情绪段用长镜头留白 |
| 广告大片（高端） | 品牌价值感 | 延迟揭示（环境/暗场蓄势→产品显影）；环境压制增强稀缺感 |

**避坑**：珠宝片最大风险是"产品保真漂移"——导演动机若定为"氛围种草"，容易让空镜抢走产品笔墨。**珠宝永远主角，笔墨最重。**

## 五、学习路径（博主原版 + 验证补充）

**博主路径**：基础（导演思维→工具→叙事方法→套路）→ 进阶（情绪化设计→节奏表达→观众心理控制）。核心：**创作思维的不断升级，而非技术重复**。

**交叉验证补充**（吸收借鉴，不作唯一标准）：
- 高阶叙事工具：视觉隐喻（构图表达抽象概念）、信息克制（故意不给看）、感官对位（视听不同步）、结构回调（Fiveable/Story2Board）
- 不同美学体系：中国画散点透视长镜头（《小城之春》）、极简克制派（《红毯先生》全片不到400镜头）
- 导演风格无统一标准：不同导演动机不同，分镜标准就不同——**借鉴方法，不套模板**
