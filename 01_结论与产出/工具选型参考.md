## 3.2 美图设计室（服饰穿戴 + AI设计Agent）

**功能A：服饰穿戴（项链平铺图→模特穿戴图）**【已查证：页面原文，designkit文章A】：
1. 拍平铺图：链条自然U形垂坠、吊坠居中、金属不过曝（长按锁焦+拉低曝光）；
2. 上传 → 模特四要素下拉选：**女/青年/中国人/标准**（做国内年轻女性市场必须选"中国人"，颈部比例不同）→ 点"生成基准模特"；
3. 选场景（如"简约居家客厅"）→ 点"生成场景图"→ 一次出4张佩戴图；
4. 不满意保持设定点"AI生成"换一批；吊坠歪→"重新生成"，位置高/低→"编辑模特"。
- **避坑**（原文8条要点）：链条扭8字→佩戴位置偏；金属过曝→材质感丢失；链条交叉/断裂→重生成或消除笔修复；金银两版必须分两次上传；界面无纯白背景选项，需抠图换白底。
- 图片比例支持 1:4 / 1:1 / 9:16。

**功能B：AI设计Agent"一键同款-模特穿戴"**【已查证：页面原文，designkit文章B】：
1. 首页→一键同款→模特穿戴→"做同款"；
2. 上传产品图（系统自动配提示词，示例"一个模特戴着这个项链，模特不露脸"，可微调）；
3. 点"开始生成"（约15秒）→ 不满意"换一批"；
4. 导出：1:1（电商主图）或3:4（小红书），PNG/JPG/SVG，高清。
- 付费：免费版带水印预览，会员无水印商用；积分制（界面显示积分）。
- 提醒：该文为营销软文性质，文中"转化率提升50%"等为宣传口径，不作为客观数据引用【已查证：原文性质判断】。

## 3.3 即梦 / Seedance（版本对比与选型）

**版本对比表**（积分/时长实测来自极目新闻记者实测截图；2.5官方参数来自字节Seed官方博客）【已查证 + 经搜索补充，详见配套研究】：

| 维度 | Seedance 2.0 Fast | Seedance 2.0（标准/VIP） | Seedance 2.5 |
|---|---|---|---|
| 单次时长 | 3–15s | 3–15s | 5–30s直出+多轮延长 |
| 分辨率 | 480p/720p（不出1080p/4K） | 480p起 | 实测720p/官方宣传4K |
| 参考上限 | 图≤9+视频≤3+音频≤3 | 同左 | 图≤30+视频≤10+音频≤10 |
| 首尾帧 | 支持 | 支持 | 支持+时间戳/局部/绿幕/白模编辑 |
| 全能参考/@引用 | 支持 | 支持 | 支持+新增R2V视频控动作 |
| 音画同步 | 原生音效/卡点 | 同左 | 优化"油腻感"，减少不受控字幕 |
| 积分（720p） | 15s≈165（Fast VIP截图口径） | 5s=70/10s=140/15s=210 | 5s=130/10s=260/15s=390/30s=780 |
| 会员门槛 | 有VIP档 | VIP通道 | 界面"会员积分消耗"；国内非会员能否直开**未经核实** |
| 真人人脸 | 暂不支持 | 同左 | 同左（官方未放开） |

**珠宝选型建议**【已查证：配套Seedance研究】：
- 无模特版10s旋转微距 → **2.0 Fast**（最便宜，够用）；
- 模特佩戴版 → 锁骨/侧脸可做；正脸写实+口播不可用（见主SOP 2.3）；
- 10–15s多卖点详情展示 → **2.0标准版全能参考**（多图@引用，15s=210积分）；
- 30s正式投放大片 → **2.5**（780积分/条≈标准会员月额度1/3，只做定稿片，不抽卡）。

**使用避坑**【已查证：配套Seedance研究】：
- 首尾帧/智能多帧/全能参考三模式互斥，别混用；
- 分辨率跳涨积分：480p抽卡定调→720p出片；30s视频480p=270积分 vs 1080p=1920积分（约7倍差价，头条博主实测）；
- 动作多/转场多的镜头，拆成多段5–10s生成再剪映拼接，别硬拉一条15s。

**2.5 用法增量与成本分工（来源：2026-10-06 收藏视频分析 #1 Xuan酱「Seedance2.5玩法大全」，借鉴选项非唯一）**：
- **成本分工建议**：评论区实测 10s 可用片≈1000 积分量级、30s 720P≈3 元/条（[评论区观众说法]）。**先用 2.0 Fast 跑粗剪/测试分镜，定稿镜头再用 2.5 出精修**，避免每帧都烧 2.5 额度。
- **主体参考锁一致性**：2.5 一次可喂 30 图+10 视频+10 音频——把同一条蓝宝石项链多角度实物图+模特参考图喂入，锁产品/人物一致性（解决无模特版/模特版之间跳款）。
- **绿幕替换**：模特佩戴镜头在纯色/棚拍背景生成，背景一键替换为门店实景/高级商场，省实拍场地。
- **3D 白模渲染**：先搭白模/线框演示项链改款结构，再渲染写实成品——对应"改款前 vs 改款后"Before/After 对比广告。
- **长连续情节**：单条出 30s 完整情节，超过则多段生成+剪辑软件拼接（该博主自己都用时间线"分成多个片段拼接"）。

## 3.8 周大生 × AI Muse Play（品牌级可落地要点）

【已查证：飞书深诺官方案例】关键成果：品宣成本降低200倍、效率提升90%、审核检测加强50%；1小时生成10组图/视频；单条素材审核修改1-2次。
可落地操作点：
1. **输入图质量门槛**：必须"清晰模特+聚焦饰品"的高质量参考图，否则效果差；
2. **产品参考图 + 详细模特特征描述双输入**：光有产品图不够，否则饰品变形/不一致；
3. **工艺专项调优**：针对"古法金"这类品牌标志性工艺要专项调优，通用模型默认还原不好（你嵌的"皇家蓝蓝宝石+金色LOVE链"同理，可把皇家蓝饱和度/金链拉丝质感列入专项词）；
4. **视频帧率按图片分辨率智能匹配**，减少AI视频噪点；
5. **非技术岗表单化入口**：填"产品名+风格关键词"即出图——SOP落地的方向是把操作做成模板，不让运营写长Prompt；
6. **协同审核流**：需求→脚本→生成素材→审核意见全线上化，版本可回溯。

## 3.10 FlovaAI（视频 Agent 平台·低成本试片候选）

> 来源：2026-10-06 收藏视频分析 / flovaa_platform_research.md（专项调研）。**候选判断限定期**：随平台版本/价格政策变化，需按实测与预算复核；并列参考选项之一，非唯一标准。

- **定位**：上游视频模型（Seedance 2.5 满血/MiniMax H3/可灵3.0/Wan3.0 等）的**聚合分发 + Skill 化工作流封装**，自己不训练视频大模型；剧本→分镜→生图→生视频→剪辑→配乐一条对话式流水线。与珠宝对位的官方 Skill：Product Promo Video / New Product Launch / E-commerce Visual Suite / Fashion Showcase【已查证：官网+多篇实测】。
- **候选判断**：**纳入"低成本试片/样片验证"备选，不进自动化主链路**；不签订阅、不年付、不大额充值。主链路仍是火山方舟 Seedance/Seedream REST API。
- **API 结论（关键）**：**无传统 REST/开放平台 API**；程序化接入靠 **Flova CLI**（可被 Codex/Claude Code 桥接，项目级粗粒度，非单镜头参数级）——自动化上限取决于 CLI 实际暴露命令集，需登录实测。
- **价格锚点**：818 促销期 Seedance 2.5 低至 0.175–0.23 元/秒（480P/720P），约火山方舟官方刊例（≈0.67 元/秒）1/3–1/4；**818 已于 9/17 结束，当前（10/6）价需登录确认**。保守预算按 0.3–0.35 元/秒测算。注册送 300 积分（≈$3）。
- **"4K"真相**：大概率是 480/720 生成 + 超分 Skill 提级，非 Seedance 2.5 原生 4K（官方 API 本就无原生 4K 档）——与我方"480p+4K 超分"路线同构，珠宝微距别对"4K"抱过高期待。
- **试片路径建议**：注册送积分跑 2–3 个 10s 480P 样片验风格 → 满意后小额充值走 720P → 终版再定是否超分。
- **风险**：促销价退坡 / 平台成立不足一年（积分预付钱包）/ 被上游模型厂商去中间化 / 商用 ToS 待登录确认。
- **姜颜篇交叉证据**：姜颜魏晋篇署名 FlovaAI，但正片 7:30 内无产品界面/参数/价格露出，仅标题署名——"效果特别棒"是成片审美证据，不能据此反推平台能力边界。

### 4.2 核心结论

1. **字节系程序化主通道 = 火山方舟（ModelArk），不是即梦官网**：Seedream/Seedance 全模型有官方 API，个人实名即开，价格与即梦 App 积分价同量级（10s 视频 API≈14 元 vs App≈15 元；30s≈78 vs 84 元）。想自动化，**第一笔投入花在火山方舟**。【已查证：https://www.volcengine.com/product/ark ｜ https://www.volcengine.com/docs/6359/1279663 】
2. **即梦画布本身不开放外部 API/Skill**（结论沿用）；底层模型经火山方舟开放；即梦 App 自身 API 需**超级会员+另购**，门槛过高不碰。【已查证：付费协议】
3. **苞米AI 无 API**（佩戴图主力保持 UI）；**剪映无官方剪辑 API**（手机端链路不变），进阶批量用 cutsdk 本地写草稿→剪映桌面端微调。【已查证：官网+官方 yaml 】
4. **自动化价值**："每个节点点一下"→"批量提交+回调回收"；但**筛图/筛视频两个质量点无法被 API 替代**，最少人工干预仍约 4 点（上传→筛图→筛视频→终检）。【已查证：底稿 §1.2 复用】
5. **不建议国内门店**：BytePlus 海外版、可灵海外版、Photoroom（美元+国际卡+连通性未核实）、即梦官网自身 API。【已查证+经搜索补充】

### 5.2 ComfyUI 选型小节

**（1）三种获取方式对比**

| 方式 | 硬件/成本 | 优势 | 劣势 | 项目适配 |
|---|---|---|---|---|
| 本地部署 | NVIDIA GPU：SDXL 12G、Flux FP8 16G 舒适、视频 24G+；**本机 Mac 不适合**（CUDA 节点跑不动视频） | 完全可控、免费、隐私 | 重资产、运维成本 | ✗ 不买（Mac+门店场景） |
| 海外云（Comfy Cloud/RunComfy/Replicate） | Comfy Cloud $20/月起；RunComfy 16G机 $0.99/时 | 免本地GPU、模型新 | 国际卡、被墙、延迟 | ✗ 日常不碰 |
| **国内在线（哩布哩布 / 吐司）** | 哩布 API 100积分=1元；VIP 1299元/年起；吐司免费100算力/天、24.9元/月起 | ✅国内直连、人民币、可开票、模型全（Flux/可灵/Seedream/Nano Banana Pro） | 免费档排队、商用逐模型看授权 | ⭐ **首选** |

**（2）与现有链路的互补（即梦精修 → LibTV/即梦图生视频 → 剪映合成）**

ComfyUI（走哩布哩布在线）**补产品图侧的缺口，不做视频主力**：
1. **ControlNet 控形**：真实项链图做 Canny/Depth 参考，锁链条走向、吊坠居中、宝石位置——比即梦"一键出"更保真；
2. **局部重绘（inpaint）**：只改皇家蓝蓝宝石颜色/金链拉丝质感，不动整图；
3. **批量流水线**：一个工作流批量出白底图/场景图，人工只做筛选（守 4 个人工点）；
4. **定制 LoRA**：把本店"蓝宝石金链"训练成专属 LoRA，风格一致。

**（3）选型结论**
- **不买本地 GPU、不碰海外云**；
- **先在哩布哩布在线 ComfyUI 跑通一条图侧工作流**：真实产品图 → ControlNet 锁形 → 局部重绘改色，产出精修产品图，再喂给现有"即梦图生视频→剪映"链路；
- 吐司作为 LoRA 素材补充；
