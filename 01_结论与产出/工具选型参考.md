## 3.1 苞米AI（珠宝垂直）

- **四大模块**（官网原文【已查证：页面原文】）：**珠宝穿戴**（一张产品图→模特佩戴图，戒指/耳饰/手链/项链，大小可调，8K下载）；**智能抠图**（珠宝特调，一键抠图优率93%，浅色珠宝不易被多抠）；**珠宝背景图**（3步生成，爆款场景智选库，可上传自有场景参考图）；**视频生成**（模特展示/360°全景/光影切换三模式）。
- **背景图→视频4步流程**（抖音口播【经搜索补充】：打开苞米AI→背景生成→上传珠宝图选模板→生成→视频生成→上传背景图→选全景展示+时长→生成）。
- **避坑**：①浅色/透明宝石生成后放大检查边缘；②产品图必须干净清晰，背景杂乱会影响自动提取（推断）；③价格/积分**未经核实**；④操作路径系第三方转述，界面按钮以实际产品为准。
- **运营背景**：深圳凡瀚智创科技（凡游在线），已服务周大生、谢瑞麟等2000+珠宝客户（搜狐新闻口径）【经搜索补充：搜狐新闻】。

## 3.2 美图设计室（服饰穿戴 + AI设计Agent）

**功能A：服饰穿戴（项链平铺图→模特穿戴图）**【已查证：页面原文，designkit文章A】：
1. 拍平铺图：链条自然U形垂坠、吊坠居中、金属不过曝（长按锁焦+拉低曝光）；
2. 上传 → 模特四要素下拉选：**女/青年/中国人/标准**（做国内年轻女性市场必须选"中国人"，颈部比例不同）→ 点"生成基准模特"；
3. 选场景（如"简约居家客厅"）→ 点"生成场景图"→ 一次出4张佩戴图；
4. 不满意保持设定点"AI生成"换一批；吊坠歪→"重新生成"，位置高/低→"编辑模特"。
- **避坑**（原文8条要点）：链条扭8字→佩戴位置偏；金属过曝→材质感丢失；链条交叉/断裂→重生成或消除笔修复；金银两版必须分两次上传；界面无纯白背景选项，需抠图换白底。
- 图片比例支持 1:4 / 1:1 / 9:16。

**功能B：AI设计Agent"一键同款-模特穿戴"**【已查证：页面原文，designkit文章B】：
1. 首页→一键同款→模特穿戴→"做同款"；
2. 上传产品图（系统自动配提示词，示例"一个模特戴着这个项链，模特不露脸"，可微调）；
3. 点"开始生成"（约15秒）→ 不满意"换一批"；
4. 导出：1:1（电商主图）或3:4（小红书），PNG/JPG/SVG，高清。
- 付费：免费版带水印预览，会员无水印商用；积分制（界面显示积分）。
- 提醒：该文为营销软文性质，文中"转化率提升50%"等为宣传口径，不作为客观数据引用【已查证：原文性质判断】。

## 3.3 即梦 / Seedance（版本对比与选型）

**版本对比表**（积分/时长实测来自极目新闻记者实测截图；2.5官方参数来自字节Seed官方博客）【已查证 + 经搜索补充，详见配套研究】：

| 维度 | Seedance 2.0 Fast | Seedance 2.0（标准/VIP） | Seedance 2.5 |
|---|---|---|---|
| 单次时长 | 3–15s | 3–15s | 5–30s直出+多轮延长 |
| 分辨率 | 480p/720p（不出1080p/4K） | 480p起 | 实测720p/官方宣传4K |
| 参考上限 | 图≤9+视频≤3+音频≤3 | 同左 | 图≤30+视频≤10+音频≤10 |
| 首尾帧 | 支持 | 支持 | 支持+时间戳/局部/绿幕/白模编辑 |
| 全能参考/@引用 | 支持 | 支持 | 支持+新增R2V视频控动作 |
| 音画同步 | 原生音效/卡点 | 同左 | 优化"油腻感"，减少不受控字幕 |
| 积分（720p） | 15s≈165（Fast VIP截图口径） | 5s=70/10s=140/15s=210 | 5s=130/10s=260/15s=390/30s=780 |
| 会员门槛 | 有VIP档 | VIP通道 | 界面"会员积分消耗"；国内非会员能否直开**未经核实** |
| 真人人脸 | 暂不支持 | 同左 | 同左（官方未放开） |

**珠宝选型建议**【已查证：配套Seedance研究】：
- 无模特版10s旋转微距 → **2.0 Fast**（最便宜，够用）；
- 模特佩戴版 → 锁骨/侧脸可做；正脸写实+口播不可用（见主SOP 2.3）；
- 10–15s多卖点详情展示 → **2.0标准版全能参考**（多图@引用，15s=210积分）；
- 30s正式投放大片 → **2.5**（780积分/条≈标准会员月额度1/3，只做定稿片，不抽卡）。

**使用避坑**【已查证：配套Seedance研究】：
- 首尾帧/智能多帧/全能参考三模式互斥，别混用；
- 分辨率跳涨积分：480p抽卡定调→720p出片；30s视频480p=270积分 vs 1080p=1920积分（约7倍差价，头条博主实测）；
- 动作多/转场多的镜头，拆成多段5–10s生成再剪映拼接，别硬拉一条15s。

## 3.6 LibTV（第三方视频流水线，批量多镜头场景）

- **归属**：LiblibAI（哩布哩布AI）2026-03-18上线，**非字节系**；模型聚合平台，底层接可灵3.0/Seedance/MiniMax等20+模型【已查证：CSDN+AIHub多源一致】；
- **Creator按钮级流程**（多源交叉）【已查证】：登录liblib.tv→开始创作→画布双击建节点（文本/图片/视频/音频/脚本5类）→脚本节点粘贴剧本点"生成"自动拆镜头→图片节点做角色三视图锁形象→脚本上方"生成分镜"批量出图（`/`调出9/25宫格）→分镜图连线到视频节点、选模型、提示词用`@`引用素材→生成→粗剪→进剪映合成；
- **Agent模式边界**：网页内Agent面板选Skill（如"高奢感TVC"）+传产品图→几十分钟出粗片，大白话可改；外部Agent走开源libtv-skills（npx skills add + LIBTV_ACCESS_KEY）全自动剧本→分镜→镜头，但**注册/上传参考图/结果检查/最终导出必须人点**；工作流可打组复跑支持批量【已查证：CSDN技术解析】；
- **移动端**：纯Web，未发现独立App/小程序【经搜索补充：未能100%排除，上线前手机浏览器实测】；
- **与即梦画布差异**：即梦智能画布是"一张图的精修台"（扩图/抠图/局部重绘），LibTV是"一条片子的节点流水线"——珠宝SOP里两者互补：即梦精修产品图→LibTV或即梦图生视频→剪映合成【已查证：配套LibTV研究】；
- **价格**：基础VIP连续包月39元/月，专业版66元/月；视频创作会员569–8499元/年【已查证：Liblib官方邀请页+36kr】；
- **避坑**：`@`引用必须写清素材角色（"@图片1作为首帧"），否则模型乱配；中间商模式，上游即梦调价会传导。

## 3.8 周大生 × AI Muse Play（品牌级可落地要点）

【已查证：飞书深诺官方案例】关键成果：品宣成本降低200倍、效率提升90%、审核检测加强50%；1小时生成10组图/视频；单条素材审核修改1-2次。
可落地操作点：
1. **输入图质量门槛**：必须"清晰模特+聚焦饰品"的高质量参考图，否则效果差；
2. **产品参考图 + 详细模特特征描述双输入**：光有产品图不够，否则饰品变形/不一致；
3. **工艺专项调优**：针对"古法金"这类品牌标志性工艺要专项调优，通用模型默认还原不好（你嵌的"皇家蓝蓝宝石+金色LOVE链"同理，可把皇家蓝饱和度/金链拉丝质感列入专项词）；
4. **视频帧率按图片分辨率智能匹配**，减少AI视频噪点；
5. **非技术岗表单化入口**：填"产品名+风格关键词"即出图——SOP落地的方向是把操作做成模板，不让运营写长Prompt；
6. **协同审核流**：需求→脚本→生成素材→审核意见全线上化，版本可回溯。
