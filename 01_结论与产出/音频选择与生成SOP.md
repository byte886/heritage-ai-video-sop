## 〇、全局速览（30 秒读完）

1. **三层声音设计**：对白/叙事层（最高优先级）→ 拟音层 → 情感层（BGM），逐层叠加
2. **声线人设四维匹配**：感知年龄 × 性别 × 能量 × 语调，对齐受众预期，不匹配会产生认知摩擦
3. **BGM 选型五步**：定情绪 → 查 BPM 映射 → 选调性 → 五维搜索 → 高潮对齐画面转折
4. **珠宝特化参数**（无模特版实测锁定）：诗性旁白 3 句 + slogan；BGM 低频弦乐+轻钢琴 70–100 BPM；拟音 `<丝绒轻抚><金属轻响>`；默认无字幕
5. **验收门禁（G5 音频子项）**：调性一致（声线/语气/节奏/音色四检查）+ 声画同步 + 无违和

## 一、三层声音设计（总则）

声音按"重要性从高到低"分三层，先定高层再补低层，**不要一开始就挑 BGM**：

| 层 | 内容 | 优先级 | 说明 |
|---|---|---|---|
| **叙事层** | 旁白/对白（人声） | ⭐最高 | 承载文案信息与情绪；受众最先感知；做不好整片垮 |
| **拟音层** | 环境/动作声（丝绒轻抚、金属轻响） | 中 | 增加真实感与"高级感"；可缺但不要乱加 |
| **情感层** | BGM（配乐） | 低 | 情绪底色；选错最容易被察觉，但优先级低于人声 |

> 依据（已查证）：声音设计三层法——对白/叙事层最高优先级 → 拟音 → 情感层：
> http://www.xdxd.cn/jxtd/xxjl/2026/73512.html ｜ https://sfxengine.com/blog/audio-layering-techniques-for-video ｜ https://www.shadowpixels.studio/blogs/sound-design-the-invisible-50-of-video

**珠宝片默认组合**：叙事层=诗性短旁白（2–3 句）或纯 BGM；拟音层=丝绒/金属轻响；情感层=低频弦乐+轻钢琴。缺人声时，BGM+拟音承担全部情绪（无字幕版适用）。

## 二、声线人设选择（配音）

### 2.1 四维匹配（选声线前先填）

| 维度 | 选项 | 珠宝片默认 |
|---|---|---|
| 感知年龄 | 青年（25–35）/ 中年（35–50）/ 沉稳（50+） | 青年偏沉稳（轻奢调性） |
| 性别 | 女 / 男 | 女声居多（珠宝受众画像）【经验值，未经核实】 |
| 能量 | 低（气声/私语）/ 中（自然叙述）/ 高（激情） | 中低（高级感 > 亢奋感） |
| 语调 | 上扬（活泼）/ 平稳（专业）/ 下沉（深情） | 平稳略下沉（珍藏/传承语境） |

**匹配原则**：声线人设要与受众预期一致——预期不符会产生认知摩擦、削弱信任感（已查证）：
- https://eliro.pro/blog/10-best-practices-ai-voiceovers
- https://www.facelessgenie.ai/blog/how-to-make-an-ai-voiceover
- https://www.lunostudio.ai/academy/ai-voice-acting
- https://vidcloner.com/blog/ai-character-voices

### 2.2 珠宝片配音参数（实测锁定，2026-10-06 无模特版成片）

- **文案**：诗性旁白 3 句 + slogan「珍藏，从此有光」（文案示例见主 SOP 1.4）
- **语速**：中慢（约 2.5–3 字/秒），给镜头留呼吸
- **语气**：克制、有留白，不读"卖货腔"
- **人设锚点**：把自己想象成"珠宝顾问在私语推荐"，不是主播在叫卖
- **配音工具**：VoxCPM2（开源、30 语言克隆、48kHz，已查证）/ minimax / fish audio（珠宝口播降本参考，来源：抖音 A19/A18 收藏解析）

> ⚠️ 合规硬墙：Seedance 2.0 系列不支持真人人脸正脸视频；**正脸写实+对口型口播走不通**（即梦教程红字，已查证：https://runyoung0613.github.io/jimeng-tutorial/ ）。锁骨+侧脸佩戴方案不受影响。配音走独立音频生成，不与视频人脸绑定。

## 三、BGM 选型

### 3.1 BPM 情绪映射表

| BPM | 情绪 | 珠宝片适用 |
|---|---|---|
| 60–70 | 舒缓/静谧/高级 | ✅ 推荐（珍藏/仪式感） |
| 70–90 | 叙事/电影感 | ✅ 推荐（Cinematic/Drama 区间） |
| 90–120 | 活力/轻快 | ⚠️ 慎用（快时尚调性） |
| 120+ | 高能/广告鼓点 | ❌ 一般不用于线下客户展示 |

> 依据（已查证）：Cinematic/Drama 60–90 BPM 情绪映射：
> https://searchsound.cloud/articles/how-to-match-music-to-video-moods-for-content-creators-a-step-by-step-guide
> 抖音博主补充：BPM 判断快慢、旋律走向判断情绪、反差配乐制造记忆点（博主一方说法）：
> https://www.iesdouyin.com/share/video/7614762186360249802

### 3.2 调性（Key）选择

- **珠宝/汽车类优先 a 小调（a 大调）**——沉稳、高级、克制（抖音博主经验，博主一方说法）：
  https://www.iesdouyin.com/share/video/7671753294146047251
- 无模特版实测：**低频弦乐 + 轻钢琴**（70–100 BPM）✅ 已用

### 3.3 五维搜索模板（找 BGM 时用）

```
Emotion（情绪）+ Instrument（乐器）+ Rhythm（节奏）+ Usage（用途）+ Negative（排除）
```
例：`elegant + string + slow + jewelry showcase + no vocal no drum`

> 依据（已查证）：https://vocalremover.easeus.com/inspiration-blog/find-the-perfect-music-for-your-video.html

### 3.4 高潮对齐（剪辑关键）

- **音乐高潮/情绪转折点与画面转折点对齐**（如蓝宝揭示帧 = BGM 弦乐进入点）（已查证）：
  https://view.inews.qq.com/a/20260115A04U4A00
- 时长匹配：视频 13s → BGM 选 13s 或裁切到高潮落点收尾；避免"音乐没放完被硬切"

## 四、拟音设计

| 拟音 | 用途 | 写法（prompt 内） |
|---|---|---|
| `<丝绒轻抚>` | 开篇黑绒显影 | 旁白起前 0.5s，气声感 |
| `<金属轻响>` | 蓝宝/链环特写揭示 | 与高光帧同步 |
| `<环境留白>` | 收尾 packshot | 音量渐低，保持寂静高级感 |

> 拟音写法沿用主 SOP 符号约定：拟音 `<>`、台词 `{}`、BGM 说明 `()`（源自 product-marketing-ad-video 参考）。

### 4.1 事件触发原则（细节到位的关键机制，2026-10-06 用户观察）

标杆片（如姜颜《两千年修行》）细节之所以到位——板凳声、环境音、人声哼气/叹气/轻笑——**不是声音堆砌，而是每个声音都由剧情/环境事件触发**：

- **环境变化 → 新空间音**：场景切换时补对应空间音（如进入室内→环境留白变室内混响；画面出现木凳→`<木凳挪动>` 同步画面动作）
- **剧情变化 → 人声微反应**：角色情绪节点补微表情声（紧张→`{哼气}`、无奈→`{叹气}`、释然→`{轻笑}`），**写在对应镜头的人声 prompt 内，且只在那个情绪节点出现**
- **无画面依据的声音不出现**：声音必须"看得见来处"，凭空加的拟音是穿帮
- **写法要点**：微表情声写进台词块 `{...}` 随情绪节点触发；环境/动作拟音写 `<>` 与画面动作帧同步；BGM 层 `()` 保持统一情绪底

> ⏳ 事件触发拟音/人声微表情的完整提示词模板，待统筹智能体（姜颜音频深挖）返回后补全示例。

### 4.2 音频生成提示词方法论（2026-10-06 调研沉淀）

> 来源：Google Lyria 官方提示词指南 / 阿里云百炼音频生成 / Suno 高级提示词（抖音博主）/ MusicSmith / fal.ai / lacuna.fm（多源交叉，已查证）。

**核心认知**：音频生成是"一段自然语言描述"驱动，不是简单关键词堆砌。主流模型（Lyria/Suno/MiniMax/即梦音频/百炼）都能从文字描述直接产出**复合音频**（人声+音乐+音效一次生成），或分层生成后混音。

**1. 音频提示词公式（多源汇总，三选一按工具取）**：
- **Lyria 官方**：`[Genre and style 曲风] + [Mood 情绪] + [Instrumentation 乐器] + [Tempo and rhythm 节奏] + [Vocal style & language 人声] + [Lyrics 歌词/台词]`
- **Suno 博主版**：`曲风 + 人声 + 歌词主题 + 伴奏 + 音质 + 情感 + 约束`
- **lacuna 简版**：`[场景/用途] + [情绪] + [谁在唱] + [音乐走向]`

**2. 关键技巧（用户问题直接相关）**：
- **描述整段，不列标签**：写"一段完整的制作指令"而非 "edm, energetic, synth"（fal.ai 实测：brief 优于 tag dump）
- **具体到乐器**："钢琴"→不如"毛毡钢琴"；"弦乐"→不如"独奏大提琴+持续弦乐垫"
- **结构标签**：`[Intro]/[Verse]/[Chorus]/[Bridge]/[Outro]` 让模型有起承转合（lacuna 数据：结构标签是出现最多的技巧）
- **时间戳控制**（音画同步关键）：`[0:00-0:10] Intro: ...` `[0:10-0:30] Verse: ...`——精确指定每段时间发生什么（Google Lyria 官方 Workflow 1）
- **负面约束**："instrumental only / no vocals / 伴奏不盖过人声 / 无杂音"（Suno 避坑关键词）
- **情绪要具体**：不要只写"sad"，写"desperate / calm melancholy / 释然"（MusicSmith）
- **音质词**：4K高清、人声清晰、立体声、低音沉稳（Suno 博主）

**3. 与视频的配合方式（回答"提示词如何配合视频、跟剪辑有没有关系"）**：

| 路线 | 做法 | 剪辑角色 | 适用 |
|---|---|---|---|
| **A. 整段一次生成** | 把视频分镜的情绪/节奏写成一段场景描述（含时间戳），一次生成整段音轨 | 剪辑仅做音量/起止微调 | seed-audio/百炼音频/即梦音频（复合音频能力强）；我方豆包系主路线 |
| **B. 分层生成+混音** | BGM（音乐模型）、旁白（TTS）、音效/拟音（场景描述）分开生成，剪辑时对齐+混音 | 剪辑是**关键环节**：各层对齐画面、控制音量比例 | 姜颜式"三层混搭"（古风弦乐+低音铺底+人声旁白）最可能是此路线——分层才能让三层各司其职不打架 |

**结论**：**"提示词配合视频"有两种实现**——路线 A 靠"提示词里写时间戳+分镜情绪"（AI 内部完成配合）；路线 B 靠"分层生成+剪辑混音"（配合在剪辑阶段完成）。是否依赖剪辑取决于你选整段生成还是分层生成；要姜颜那种"三层各司其职"的效果，分层+混音更可控。

**4. 我方落地方案（豆包系）**：
- 珠宝静物片（无模特版）：路线 A——用 seed-audio/音频生成接口，按分镜时间戳写场景描述一次生成
- 故事感/模特版：先按路线 A 试整段；若要三层混搭质感，改路线 B 分层生成（BGM 一层 + 旁白一层 + 拟音一层），剪辑对齐

> ⏳ 统筹智能体（姜颜音频深挖）返回后，补"三层混搭"完整分层参数与时间戳示例。

### 4.6.1 三层混搭完整参数回填（姜颜魏晋篇，路线 B）

> 依据：7687150659992309042_姜颜_audio_analysis.md（[用户听感]三层混搭原话 + [分析推断]分层参数）。

| 层 | 承担 | 频段/位置（推断） | 相对音量（推断） |
|---|---|---|---|
| 人声旁白（叙事层） | 故事讲述 | 居中、靠前 | 0dB 基准（最前） |
| 古风弦乐（旋律层） | 时代感/记忆点 | 中高频 800Hz–4kHz | -6dB |
| 低音铺底（氛围层） | 史诗厚度/空间纵深 | 低频 80–250Hz | -12~-18dB |

**补位逻辑**：人声旁白停顿处弦乐自然浮出补位；弦乐休止时低音继续托住——三层轮流"说话"，避免同时满负荷。**情绪随剧情消长**：动作段低音加厚 → 悲情段弦乐 solo → 收束段转暖变薄。
**判定：路线 B（分层生成 + 剪辑混音）**——三层可分离，先各层生成再叠 TTS 旁白对齐画面（[分析推断]）。
分层提示词候选（[分析推断]，非博主原稿）：弦乐层 `Chinese ancient style, solo guzheng & erhu strings, melancholic epic, slow 60-70 BPM, instrumental only`；低音层 `deep cinematic bass pad, low string drone, tense-to-warm, no melody, occupies low frequency`；旁白层 `warm narration, Mandarin, calm storytelling, centered vocal, (do not let music cover voice), breathy micro-reactions`。

### 4.6.2 旁白即转场（来自分镜衔接片 #5 Insight AI）

- **技法**：场景切换点用一句描述性旁白缝合两个场景，替代硬切。原片演示："切到下一个场景了，让整座山缓缓落进眼里"——观众耳朵先被告知"要换场景"，眼睛再看到新画面，转场不突兀。
- **句式模板（借鉴，复现需实测）**：`"切到下一个场景了，让<主体>缓缓<动作/进入画面>"`。珠宝片试套："换一个场景，让蓝宝石的火彩缓缓落进眼里"。
- **配套节奏**：讲解段口播密 → 成片展示段口播让出、画面放慢，音画同呼吸。

### 4.6.3 口播让位 / 三段式（来自 #4 MiniMax H3、#3 Opus 5.5）

- **口播优先型原则**：教程/资讯类内容＝人声为绝对主声道，BGM 压到最低或无；BGM 让位，环境音只在 hook 前 3 秒保留。
- **三段式结构（#4 可借鉴）**：① hook 用"带人声/环境音的 AI 成片"15–20s 先声夺人（音频真实感＝能力证据）→ ② 教程段男声步骤口播 + 零 BGM + 每步大字幕 → ③ 成片展示段口播暂停/压低，**声音留白让画面自己说话** 3–5s。

### 4.6.4 事件触发拟音提示词挂载模板（回填 4.1 节）

> 依据：7687150659992309042_姜颜_audio_analysis.md 第三节（[用户听感]触发机制 + [已查证画面]事件帧）。**写在每镜提示词末尾，随画面事件挂载：**

## 五、验收检查（G5 音频子项·强制）

出片后逐项检查，任一不满足 → 不进下一步迭代：

| 编号 | 检查项 | 通过标准 | 方法 |
|---|---|---|---|
| A1 | 声线调性 | 感知年龄/性别/能量/语调与受众预期一致，无"AI 播音腔"违和 | 通听 2 遍（无画面/有画面各 1 遍） |
| A2 | 语气节奏 | 语速中慢、留白够，不赶 | 对照文案时间轴 |
| A3 | BGM 调性 | 情绪匹配（舒缓/电影感），无明显鼓点违和 | 与 3.1 表对照 |
| A4 | 声画同步 | 高潮与揭示帧对齐；拟音与动作帧同步 | 逐帧听+看 |
| A5 | 人声/音乐比例 | 旁白清晰 > BGM 底；BGM 不压人声 | 音量表抽查 |
| A6 | 字幕/音频调性 | 有字幕时：措辞与声线同调性；无字幕时：确认无需字幕（默认无字幕） | 文案与成片对照 |

> 音频属 G5 评估门禁子项（详见 `02_决策记录/评估迭代机制.md` G5）；调性检查含"声调/角色/人设"三维（用户要求，2026-10-06）。
